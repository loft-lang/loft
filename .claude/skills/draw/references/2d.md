# 2D drawing — the shipped tool and how to run the loop on it

The 2D instance of the method is `sketch/draw.py` (repo root). It is a persistent
renderer over an annotated text scene file; you edit the scene, it re-renders, and
it writes both a cheap text channel and an image you `Read`.

## Run it

```bash
python3 sketch/draw.py path/to/scene.draw     # renders + watches; re-renders on save
SKETCH_OUT=/dir python3 sketch/draw.py scene.draw   # choose output dir
```

There is no single-render mode — the tool always enters the watch loop.  As an agent,
run it in the background (or kill it once `stats.txt`/`canvas.png` appear) and re-read
the outputs after each scene edit.

Requires Pillow. Outputs go to `$SKETCH_OUT` (default `<tmp>/loft_sketch/`), **never
into the repo**:

- `stats.txt` — **the cheap channel**: ASCII density map + element bboxes + `CHECK`
  results + a **composition / notan report**. Read this most iterations; it's text.
- `canvas.png` — the drawing (the expensive look; spend on gestalt + affect).
- `canvas_check.png` — drawing + target guides (green landmark, gray bboxes, red =
  failed check). Read when you need to *see* a gap.
- `preview.png` — a smaller, cheaper image look.

Editing the scene file *is* undo (reload on save). Rendering is supersampled, so
edges are anti-aliased — never hand-place anti-aliasing.

## Scene grammar

Coords are **fractions** of the paper (0..1); origin top-left, **y grows down**.
Gray `L` is 0..1 (0 = black). Colour `rgb` is 0..255.

```
size WxH
Background top=A bottom=B                 grayscale sky gradient (A top → B bottom)
Background topc=R,G,B botc=R,G,B           colour sky gradient
name <element>                            tag the following marks (so they're measurable)
Line (x1,y1)[@N] - (x2,y2)[@N] [w=N] [stroke=R,G,B]
Circle (cx,cy) r=R [n=N] [flat=F] [w=N] [<fill> | stroke=R,G,B]   round (aspect-corrected)
Poly (x1,y1)[~][@N] (x2,y2)[~][@N] ... [w=N] [<fill> | stroke=R,G,B]   stroke, or filled
  <fill> = fill=L | rgb=R,G,B                                    solid (gray / colour)
         | grad=R,G,B>R,G,B [dir=ax,ay,bx,by]                    linear gradient (c1→c2)
         | radial=R,G,B>R,G,B [at=cx,cy,r]                       radial gradient (centre→edge)
landmark <name> = <value>
check <prop> <op> <term> [tol T]          op: ~ < > <= >= == ; arithmetic on the RHS only
                                          prop: <element>.{left,right,top,bottom,cx,cy,w,h}
# ...                                      comment / SHOULD note (ignored, searchable)
```

- A shape with a `<fill>` is **filled**; with neither fill nor `stroke=` it's **stroked**
  in dark ink. Painters' order = source order (sky, then masses, then detail on top).
- **Gradients model form** — the jump out of flat-mask. `grad=` is a linear lit→shadow
  plane; `radial=` runs centre→edge — a radial on a face gives a lit-centre,
  shadowed-edge roundness no flat fill can. Computed small, then supersampled, so the
  transition is smooth. Use them for *form* (a face, a cloud belly, a lit plane).
- **`~` after a Poly point makes that point a smooth curve** (Catmull-Rom); no `~` = a
  corner. Mix them: smooth the organic edges (a jaw, a hill, a cloud), corner the
  structural (a roof ridge, a wall). The outline then reads hand-drawn, not faceted.
- **`stroke=R,G,B` colours a stroke** — the **texture channel**. Light + shadow strokes
  fanning along a growth direction make hair / beard / fur / grass; curve them with `~`
  so they read grown, not combed. (A stroke with no `stroke=` is dark ink.)
- **`@N` after a point sets the pen width *there*** (strokes only); the width tapers
  linearly between points, rendered as a filled ribbon. A strand thick at the root
  (`@6`) thinning to a tip (`@0.5`) reads as a real hair — a uniform line reads as wire.
  Combine with `~` for a curved, tapering strand; `w=N` is the default where `@` is absent.
- `flat=F` squashes a circle vertically (negative F makes it taller — useful for an
  egg/face oval).
- Put the **target feeling** and the **`# SHOULD:`** intent next to each element as a
  comment; `grep -n SUN scene.draw` to find a spot again.

### The composition / notan report (in `stats.txt`)

Global facts no per-element check can give: L/R and top/bottom weight balance, the
**center-of-mass of the darks vs the thirds grid**, the **value spread** (notan
health — muddy mid vs clear dark/light), and the **largest flat region** (dead
space or dominant field). Use it as your digital thumbnail: judge composition on
this coarse map, not by scrutinising the detailed image.

## Earned 2D rules (read before drawing; they save whole passes)

- **Round circles** are aspect-corrected by `Circle` already — equal fractional radii
  would otherwise render as an ellipse on non-square paper.
- **A bare circle reads as a ball.** A *sun* needs short radial rays (its diagnostic
  cue) — but **not** long beams across the scene (those read as wires).
- **A cloud** = one soft, irregular, ragged silhouette with the interior withheld —
  **not** crisp overlapping circles (those read as bubbles). For a *dark* cloud, fill
  it dark with a soft/low edge; a crisp outline can't be ominous.
- **Dominance ≠ looming.** A big mass that floats high with empty space under it
  doesn't oppress; oppression needs the underside *close* over the subject and the
  dead band removed. (Don't trust `cloud.bottom < house.top` — that only says
  "above"; check a *small* gap: `cloud.bottom > house.top - 0.06`.)
- **Each measurable thing gets its own `name`.** Tagging a sub-part (chimney, light
  spill, smoke) under a parent bloats the parent's bbox and breaks its checks.
- **The composition critic tracks DARK mass** — in a light-on-dark dusk scene the
  focal point is the *bright* face/window, which it can't see, so it may cry
  "dead-centre/static" while the real focal is well-placed. Judge the bright focal
  by eye.
- **Faces** (the hardest 2D subject):
  - Go **line-forward** — wrinkles *are* lines, and line is recognition's native
    channel. Proportions via checks (eyes at the head's vertical midline, nose below
    eyes, mouth below nose, ~5 eyes wide).
  - **Pupils give gaze and life** — a lidded almond with no pupil is a blank mask; a
    tiny bright **catchlight** in the iris is the cheapest "this eye is alive" mark.
  - **Model the form — don't flat-fill it.** A **radial gradient** (lit centre →
    shadowed edge) rounds the face out of mask-flatness; **warm skin tone** keeps it
    alive (grey = corpse). The reachable ceiling is a **handmade-real / textured
    illustration**, not photoreal skin — per-pore micro-texture is past these
    primitives. *That's* the floor; don't chase photoreal past it.
  - **Hair / beard / brows are a texture, not a silhouette.** Fill the mass, then lay
    light + shadow **`stroke=` colored strokes** fanning along the growth direction
    (curve them with `~` so they read grown, not combed). A flat grey beard beside
    detailed eyes is exactly the uncanny seam (see the uncanny failure mode in
    SKILL.md).
  - **Break symmetry; take the gaze off-axis.** Mirror-identical eyes/brows and a
    dead-centre stare are the strongest uncanny triggers for a face — offset one eye a
    little, vary the brows, nudge both pupils a hair off-centre.
  - **Commit to one scale** — a portrait (head-and-shoulders, cropped) *or* a figure
    (small head, ~1:7 body). A portrait head on a figure body is a bobblehead.
  - **Age cue-set:** grey hair (often a bun), hooded eyes + bags, nasolabial folds,
    a thin downturned mouth, forehead/eye-corner lines. A few bold, not many faint.
- **Hair / fur / beard — a *mass*, not a bundle of strands.** The #1 mistake is drawing
  individual hairs; enumerated strands always read as wire / spaghetti / a comb-over.
  How it's actually done:
  - **Value first.** Block the mass as a filled shape with a light→shadow gradient —
    *that* is the hair. Strands are a finishing accent on top, not the substance.
  - **Few strands, only where they earn it:** the **silhouette** (broken and wispy, a
    few strays past the edge — a hard outline reads as a helmet/wig), the **sheen band**
    (the ribbon of light across the crown), and **clump partings**. Strands spread
    evenly across the interior are the dead "combed" tell.
  - **Clump, don't comb** — irregular spacing, length, thickness; grouped, with strays.
  - **Flow follows the form** — curve each strand (`~`) along the growth direction,
    wrapping over the skull / jaw; the direction turns where the form turns.
  - **Taper every strand** (`@root … @tip`, thick→~0) — uniform width is wire.
  - **The dark gaps matter as much as the light hairs** — a few occlusion strokes
    *darker* than the mass, between clumps, carve the locks. Layer order: dark mass →
    mid shadow → fewer, lighter strands on top → a few bright flyaways last.
- **Draw from a reference — the open corpus matches this tool's marks.** When fur /
  foliage / grass is the subject, pull a public-domain plate and compare region by
  region (the strokes there *are* tapered ribbons + thin lines, the same vocabulary):
  - **Fur/animal form:** Dürer's *Young Hare* (the canonical fur study — strokes follow
    the form, clumps not strands, broken silhouette); **Biodiversity Heritage Library**
    (`flickr.com/photos/biodivlibrary`) and **Smithsonian Open Access** (CC0) for any
    species; taxidermy photos for rare genuine top-down views.
  - **Foliage/landscape/ground:** **Van Gogh** reed-pen drawings (each texture = a
    distinct repeated mark: grass ticks, foliage clusters); **Rembrandt** landscapes via
    Rijksstudio (tree = a canopy mass with a drawn edge, not leaf-by-leaf); Hokusai/
    Hiroshige for codified low-detail marks. Met / NGA / Getty open access for more.
  - **Technique text (read, don't copy):** Ruskin's *Elements of Drawing* (trees, rock,
    water as structures), Pennell's *Pen Drawing* (the hatching/stippling catalogue).
  - All PD/CC0 — safe to study and derive from. A project can keep a small fixed set
    checked in beside its sources as a redraw target (crawler does: `assets/sprites/ref/`).
- **Repeated marks / arrays (veins, leaflets, fur clumps, grass, scales, stripes, a tiled
  pattern) — never a uniform row, and hide the construction.** N identical marks at an even
  spacing is the deepest "machine-made" tell; the fur *clump-don't-comb* rule above is one
  case of a general law. Two separate things to get right:
  - **Not equal — *trend* AND *jitter*, two independent axes.** *Trend* = a deterministic
    ramp along the run that follows the FORM (veins shorten toward the leaf tip, leaflets
    diminish distally, spine fur longer than flank) — this is what makes the array read as
    *attached to* the form, not scattered. *Jitter* = seeded irregularity of spacing /
    length / angle — this breaks the *mechanical* read. They don't substitute: veins are
    high-trend / low-jitter, fur is low-trend / high-jitter. **Mirror-paired marks must stay
    equal ACROSS the axis** (left vein *i* = right vein *i*) or the form reads damaged — so
    jitter the symmetric *unit*, not the element. Uniform (trend = jitter = 0) is the right
    special case ONLY for man-made regular patterns (a cloth check, crenellations) — and
    even there, fray the edges.
  - **Hide the construction, keep the identity.** Jitter alone does *not* hide a pattern —
    the underlying *period survives* perturbation and uniform noise is its own signature.
    Break the *incidental* regularity (perfect spacing/length), keep the *diagnostic*
    regularity (it IS a row of veins). Strong hiders, cheapest first: (1) **correlated
    variation** — drive spacing/size from a slow low-frequency field so marks bunch in
    CLUMPS and gaps, not independent wobble; (2) **aperiodic placement** — golden-angle
    (137.5°) for radial, low-discrepancy offsets for linear (phyllotaxis is nature's own
    anti-row trick); (3) **occlusion + layering** — overlap marks into clumps and BURY part
    of the array under bigger forms; stack 2–3 passes at different scales/seeds (no new
    tool — just draw order); (4) **fray the boundaries** — density falls off, strays cross
    the silhouette, no clean clip-line or tile seam (the boundary betrays a pattern fastest);
    (5) **a tonal wash over the field** — the eye reads the big value shape first and the
    regular marks recede (*value first*, again). All deterministic (golden angle, hashed
    value-noise, low-discrepancy, index-derived variants) → renders stay reproducible. The
    **Van Gogh** reed-pen reference is the answer key: thousands of repeated strokes that
    never read mechanical, via density variation + flow-along-form + varied length + tonal
    grouping. Judge "does this read as *generated*?" in-scene, not just per mark.
  - **Tooling.** ⚠ NOT in `sketch/draw.py` — the `Petals` / `Fronds` ops below exist
    only in the plan-146 oracle fork
    (`doc/claude/plans/146-content-delivery/corpus/oracle/draw.py`), and
    `sketch/draw.py` SILENTLY drops lines it does not recognise, so writing them in a
    scene here renders nothing with no error.  In that fork: the radial case is the
    `Petals` op (here congruent is *correct* — a
    flower reads as equal petals); the linear case is **`Fronds`** (tapered strokes
    rooted along a spine — veins, barbs, fur clumps, grass, a fringe), with the non-uniform,
    construction-hiding output as the DEFAULT (placement on a seeded low-frequency field,
    len/angle on a form-trend ± jitter, mirror units shared, ends frayed) and uniform
    (`jitter=field=fray=0`) reachable for man-made patterns. **`depth=2` makes it FRACTAL** —
    each frond grows its own scaled sub-array, the self-similar structure of real leaf
    venation (midrib→primaries→secondaries) and any branching natural form. Occlusion + the
    tonal wash stay composition (draw order + gradients you already have).
  - **The man-made opposite — DECORATIVE patterns** (wall/wallpaper damask, curtain prints,
    motifs on objects): here you WANT the uniform special case (`jitter=field=fray=0`, crisp),
    and you hide the "flat stamp" via the **surface** — conform to folds, perspective,
    lighting, wear — NOT via jitter on the marks. Needs (future, library-tier): symbol-capture
    + affine `place` → grid/lattice with wallpaper-group tiling (offset/mirror/rotate) →
    clip-to-region → surface-conform/warp. The motif's own internals still use `mirror` +
    fractal `depth`. Same toolkit as foliage, opposite default.

## A worked example

`sketch/scene.draw` + `sketch/example.png` are the canonical worked example — an old
woman at dusk before her lit house. It exercises colour, value, the composition
report, named elements, and the metric checks. Read the scene file alongside the
render to see how the grammar maps to the image.

## The arc a real drawing went through (so you expect the shape)

symbol block-in (cube + bubbles) → coherent *place* (real house, world that holds)
→ *composed* place (low horizon, looming mass — mood by arrangement) → *value* (dark
cloud, glowing horizon, lit window — the dusk feeling) → *colour + soft edges* (warm
skin, warm/cool dusk — the largest single jump). Each step was one pass with a
find→fix→verify; none arrived in one shot.

A portrait pushed *into and out of* the uncanny valley: flat masses → **radial-modelled
face + warm skin** (form) → **smooth-spline outlines + gradient hat** (organic, not
faceted) → **colored-stroke beard/brow texture + broken symmetry + off-axis gaze**
(climbing out toward handmade-real). The valley appeared exactly when realism in some
channels met regularity in others; the fix was never "more detail" but "pick a side."
