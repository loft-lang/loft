## Gotchas met

- `find_problems.sh` exports `LOFT_NATIVE_BACKEND=c`; `--native` builds through C by default
  since #2516, `--native-rust` is the rustc writer.
- Comparing two loft binaries' units needs each binary's OWN tree's survey script: the unit
  embeds the runtime from `src/c`, so a mixed run reads every unit as different.
- A `--force-with-lease` sha comes from `git rev-parse`, never typed.
- A suite receipt's CHANNEL/ARMED/WITNESS/HOLDS go BELOW the `@falsified-at:` line, which names
  a PUBLIC sha (`scripts/falsify-review.py --check`).
- `/tmp` is a 7.5 GB tmpfs; Claude Code's temp dir there has a quota (it hit at ~4.2 GB and
  blocked every shell command).  Keep build and survey scratch under `target/cgen-work/`.
