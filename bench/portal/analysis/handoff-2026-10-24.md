## Owner rulings made today (also in memory)

- **Only GENERAL optimisations.**  A rewrite must speed up a construct everywhere, never one
  routine's shape; the bench against its Rust twin measures a quick language, it is not the
  target.  `(R-ParRows)` (par-only) was built and REMOVED for this.  A layout regression is
  noted with evidence, never fixed with alignment/ordering code unless the remedy is easy and
  consistent (`loft-optimize` skill § Tempting shortcuts).
- **Judge work by SHIP against CHECKED.**  The ship column is the routine as a game's release
  build would compile it, fault checks dropped.  `formal/performance.md` § The bug line: a ship
  gap over 3.5× is a bug, ONE issue per class of problem naming the routines its fix must improve
  (the acceptance check); the line ratchets down to 3×.  The guarantees' own cost is optimised
  but is not a bug.
- **File an issue only when its repro fails on the latest `main`**, never for what this branch
  broke (that is the branch's to fix, in the commit message).
- **The ship build recompiles every library from source**; precompiled libraries serve quick
  development only.  @PLN201 (`loft-lang/plans#201`, `doc/claude/plans/201-ship-tier/`) is its
  design: a ledger of fault-free checked runs on the IR, then the build.  Open owner question in
  it: function coverage or per-site coverage.
- **ANSI C** (@PLN200, another agent) is generation validation only for now — no C bench lanes or
  twins; the preferred endpoint later (not 2026).  Decide rewrites on the IR.
- `~/.local/bin/loft` may be replaced with `origin/main` at any time (`make install-main`, on
  `tuxedo-work`, not on this branch yet) — the control for "does main have this failure".

## Working notes

- One heavy job at a time; `/tmp` is a RAM tmpfs with a per-user quota — run
  `ownership_drop_gate` with `TMPDIR=~/.cache/loft-tmp`; `make sweep-scratch` reclaims.
- A package's native half takes `loft-ffi` from crates.io: a local fix needs `[patch.crates-io]`
  AND `cargo update -p loft-ffi` in that clone, or the old lock wins.
- Ship-lane A/Bs: `LOFT_NO_FAULT_FLAG`, `LOFT_NO_FAULT_FLAG_UNROLL`, `LOFT_NO_POOL_RESET`,
  `LOFT_NO_GUARDED_CHAIN`, `LOFT_NO_BOUNDED_NEST`; `gap_report.py` runs on the ship form with
  `LOFT_RELEASE_PASS_PROBE=1 … --lean`.
