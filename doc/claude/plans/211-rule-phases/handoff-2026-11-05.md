## The ruling that shapes what follows (owner)

"This dynamic build that can change doesn't need to be fully optimized.  The ship build is not
dynamic anymore so it can have more optimizations applied."  NATIVE.md § Optimisation tiers: the
semantics tier (plain `--native` / `--native-c`, the live tier shipped) is an OPEN program; a
whole-program rewrite that needs the closed program does not run there, and NO writer keeps a copy
of it for that build.  Consequence: such a rule is checked CLOSED (`--lean`) — a plain native run
never reaches the IR value-record pass (a planted fault passed `--native-c` and failed `--lean`).
