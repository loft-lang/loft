## Every change, the routine that worked

1. Hand form or rule text first (the plan's `hand/<routine>/` holds the forms).
2. Build; the rule's guards through `scripts/c_sweep.py [--asan|--poison] FILES` (C against the
   interpreter); count that the rewrite fires in each guard (grep the emitted C).
3. Plant a defect per condition, rebuild, see each fail the guard alone; undo the plant with an
   exact-string edit (never an empty pattern — it cannot be found again).
4. Switch A/B on the libraries where it fires: `target-exp/tools/abpkg.sh PKG "ENV_A" "ENV_B"`
   with `LOFT_AB_BIN`, `CC=gcc|clang`; list where it fires by grepping the benches' emitted C.
5. Full `c_sweep.py` (≈ 15 min) and the C test binaries (`c_emit push_fill push_hoist
   push_window locked_writes foreign_store`), both clippy variants, `cargo fmt --check`
   (ignore `loft-ffi`, local rustfmt is newer), `scripts/feature_coverage.sh --check` for a new
   file (tag it `@I68`), `cargo test --lib platform_census` for a new script.
