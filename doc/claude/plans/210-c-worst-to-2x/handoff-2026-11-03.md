## Traps met

- **A detached run (`( … ) &`) gives no completion notice** — I reported a finished validation as
  still running for six hours.  Use the tool's background mode, or check the output files' `exit`
  lines.
- **Poison-sweep every new rewrite.**  `(R-Peel)` carried the writer's `bound` across copies and
  freed a call buffer; only the poison sweep saw it (loft3 fixed it, `3f4abdd50`).
- **A one-routine driver can disagree with the full bench** under clang (inlining budget in the
  larger unit): `materialise` 2.45× cut vs 3.7× full.  Price in the full bench before trusting a
  ratio.
- **Code placement moves gcc times with identical instructions** (`materialise` +25 %, gone under
  `-falign-loops=64`): record it with the instruction count, don't code around it.
- **A per-read test the compiler doesn't hoist costs everything** — `loft_grid_fits` with a division
  gave no gain; with a checked multiply 3.06× → 1.70×.
- **The line marker before a `for` block**: "the statement before" must skip `Value::Line`.
- **cargo fmt reflows plant lines** — re-read before inserting a plant, and check the plant
  actually emitted (a no-op plant reads as "not caught").
