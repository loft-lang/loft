## Where it stands

- **The interpreter in loft** (`selfhost/src/`): `lower.loft` lowers the image's IR to flat
  ops, `run.loft` runs them with one stack per kind (int, float, text; `&text` as an index on the
  int stack; a record reference as three integers on it).  It covers scalar arithmetic, control
  flow, calls, texts, `&text`, every format spec, the census's small operators, text slices,
  the casts, and **S3's first slice: records** of every field width, texts, embedded records
  and copies, in the C runtime's stores through `crt`.
- **Census** (`python3 selfhost/cover/census.py --loft target/debug/loft`, with
  `LOFT_SUITE_DIR` set): 1026 programs, **60 pass, 0 leak, 0 wrong, 0 crash, none swept** (27
  before S3).  Refused next: vectors 451, struct enums 88, hashes 58, `OpNewRecord` 35, tuples
  32, function values 32, a `&` record 31.
- **Ownership at run time — BUILT (owner ruling, 2026-10-28):** one owner table in `run.loft`
  (`(O-Owner)`: per store, the owning slot, the frame holding it in flight, or nobody) decides
  every bind (adopt / copy / view) and gates every free; a return sweeps what its frame still
  owns.  No callee analysis.  1b-s3.md § Ownership at run time.  An operator that stores a
  reference INTO a record (`OpSetDbRef`, a vector push of a record) must move ownership to the
  container in the table; refused until it does.
- **Speed:** unchanged (~20× the Rust interpreter on fib; loft-13 owns 3c/3b, register X21).

## How to run the package tests on the native backends

`tests/selfhost.rs` runs them on the interpreter only.  For `--native`/`--native-c`, emit each
kernel's image, C and type table into a directory and point the same three variables at it
(`LOFT_SELFHOST_IMAGE`, `LOFT_SELFHOST_KERNELS`, `LOFT_SELFHOST_NOT_AN_IMAGE`), then
`loft test --native` / `--native-c` in `selfhost/` and `selfhost/crt/`.  The `.ctypes` file is
`c_type_table` of `tests/selfhost.rs` over the emitted C.
