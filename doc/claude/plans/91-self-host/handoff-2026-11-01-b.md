## How to gate a batch (unchanged, plus)

Runner build → `cargo test --release --test selfhost` on the three backends → census (no program
lost) → `selfhost/compare/compare.py --layers out,alloc,leak,binds,slots` over every passing
program → a row in the record doc → commit.  After a compiler change rebuild the op-census loft
(`cargo build --release --features op-census --target-dir target/op-census --bin loft`); the
comparison now rebuilds its runner when a C runtime header changes.  Run suites with
`LOFT_SUITE_DIR=../loft-suite-91` — `make suite` defaults to `../loft-suite`.
