## How to gate a step (scratchpad scripts are lost on /clear — rebuild them)

1. Build the runner through C: `loft --native-c --ship --out <dir> selfhost/cover/run_program.loft`
   with the CURRENT `target/release/loft` (a stale copy lacks the compiler fixes).
2. Census: `LOFT_SUITE_DIR=../loft-suite-91 python3 selfhost/cover/census.py --jobs 6`; diff the
   tsv against the previous one for regressions.
3. Strict comparison over every passing program: `selfhost/compare/compare.py --layers
   out,alloc,leak,binds,slots <files>` (it builds with `target/op-census/release/loft` — rebuild
   that after a compiler change: `cargo build --release --features op-census --target-dir
   target/op-census --bin loft`).  Pass ABSOLUTE image paths to `run_program`/`reports`: a
   relative path is read against the binary's own directory (1b-compare.md).
4. `cargo test --release --test selfhost`.
