## What this session added

- Unhelpful diagnostics removed:
  - a `struct` defined twice reported every shared field as "already declared" (the second
    definition's fields were parsed into the first); the conflict messages read "a enum" —
    `DefType::described` names a kind with its article;
  - the uplifted-rlib "is STALE" warning, which reached a reader that cannot act (loft never
    links the bare rlib; `make check-rlib` serves the tools that do);
  - a bare lowercase arm name (`other => …`) gave three errors; it now gives one that names
    the `other: _` spelling, and the arm is read as that catch-all for recovery.
- The elaborator: `place_root`, `one_op_wrapper` and `compound` no longer copy the node they
  walk (`view-copied` gone at those three sites).
- **loft#2389** (rustc-native): a record local whose first bind is a null-init below the top
  level — a later arm of a tail `match`, a self tail call's loop — got its `let` inside that
  block while the function-level free named it (`E0425`).  `collect_nested_null_inits`
  replaces the call-argument-only collector (loft#1852) with the general rule: such a local is
  bound up front, which changes no meaning because its first bind IS the sentinel.
- **loft#2390** (rustc-native): an exhaustive `match` whose arms all `return` wrote its
  fallback as `()`.  `if_value_type` carries the delivered type down the `else if` chain from a
  `return` or a bind; `null_arm_type` uses it when the arm beside the absent one diverges.
- **loft#2388** filed, not fixed: `x = <value that never arrives>; x + 1` is an ICE on the
  interpreter and C.  `(C-Never)` says the program is valid, so a refusal would be a new
  deviation; the open design point is how a read of a `Never`-typed local lowers.
