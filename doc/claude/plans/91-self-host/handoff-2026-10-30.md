## The rules this work runs under (owner, 2026-10-30)

- **A reimplementation, not a new language** (goal constraint 5, [1b-interpreter.md](1b-interpreter.md)):
  the same IR, the same bytecode out of the lowering (the port of `state/codegen.rs`), the same
  memory structures, the same operator semantics.  No owner table, no sweep.
- **The reference improves at its home** ([1b-reference.md](1b-reference.md)): the second
  implementation shows what fell through the cracks of the first.  Every difference the
  comparison finds goes through `doc/claude/formal/` first (the rule; extended first when it
  cannot express the case), then the registers (a chapter deviation, or a
  [STORE_MODEL.md](../../STORE_MODEL.md) row — where the rules are silent, STORE_MODEL's own
  rule decides: the C runtime's model is the standard unless the interpreter measures better),
  then the change on the losing side, and the loft interpreter follows the Rust one last.
- **Designs before code; the owner evaluates.**  [1b-readability.md](1b-readability.md) is
  designed and not built — nothing from it is to be implemented until the owner ratifies.

## How the instruments are run

- `selfhost/compare/compare.py --keep …` keeps the traces; `scripts/c_alloc_diff.py` (its
  `program_events` is shared) prints the INTERPRETER in the left column, the C in the right.
- A per-function split of a kernel must cut `main` alone (`sed '/^fn main() {/,/^}/d'`) — the
  hash kernel's `main` is not its last function — and must print every verdict: a grep for
  `DIFFERENT` alone hid front-end `ERROR`s once and read as "all equal".
- `LOFT_TRACE_BIND=<file>` (Rust, `generate_set`) and the loft runner's `write_binds` write the
  bind table; `LOFT_TRACE_CLEAR=1` names each vector clear and store reset.
