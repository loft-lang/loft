## Rust fix this session (`9d0238677`)

**A literal rebuilt in place read its collection member through a view of the destination after
the re-init** — `code = NdBlock { tag: […], block: [bl] }` with `bl = block[0]` of a `match` on
`code`.  Silent wrong on both backends, on main.  Three gaps of one invariant
(`(R-InPlaceLiteral)`: every field is evaluated before the first write, through any view):
the collection-member watch matched only the destination's number (now `store_viewers`,
`Parser::arm_rebuild_watch`); it was never armed for a variant of the local's enum
(`is_variant_of_local`); and `store_viewers` read only a local's last bind's deps, missing a
view rebound on one path (`Variable::viewed`, filled by `Function::note_bind` at the end of
`parse_assign`, `(O-Complete)`).  Guard: suite
`rules/rewrites/R-InPlaceLiteral/a-variant-rebuilt-in-place-reads-its-collection-member-through-a-view.loft`,
falsified against installed main on both backends.

Instruments: `LOFT_STRICT_STORES` and `LOFT_POISON` stay silent on this class (the store is
re-initialised, not freed); what found it was diffing `LOFT_LOG=ir:n_` of the elaborator built by
base and by HEAD, then a `LOFT_NO_*` switch bisect.  `loft p.loft` may serve a CACHED bundle
built before a compiler change — use `LOFT_NO_CACHE=1` for every A/B.
