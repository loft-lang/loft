## Ported (elaborator)

  enum, `c == null` on a collection, a nullable value into a dense slot, declared copies of a
  record or vector local (`record_copy_type`).
- Struct enums: variants and their records, the schema (`PtEnumValue`, the enum sized by its
  largest variant, `finish_enum`), literals, `match` (unit / struct patterns, plain-field
  bindings), `is`, unit variants as values (`EnumUnitLit`), a variant stored where its enum is
  declared, returned from `-> E`, passed as an argument, a struct-enum field held inline.
- Plain-enum vectors (`OpPushEnum`, `OpGetEnum`).
- The text-return promotion: the in-pass bind (`do_tret_bind`, `text_verdict` =
  `classify_text_return`) and the after-pass promotion (`el_tret.loft`), its candidates asked of
  `own::text_return_orphan_risk` (the oracle `own.loft` already ports); a text `return`.
- `parse_var`'s rule: a read borrows its variable, except a text read first into a local bind's
  destination (`read_into`, `leftmost`).
- `field += [literal]` whose record item reads the field's record under another name builds in
  a vector of its own (main's loft#2397 fix, `alias_reads`).
- An `OpDrop` hook is a method.  The drop cascades (`el_drop.loft`, `synth_drop_cascades`):
  fields, vector fields, vector types; enum variants, keyed collections, iterators, tuples and
  owner slots refused by name.  A program that needs a cascade is still refused ("a type
  holding a droppable") — without that refusal 1515-a-join-return agrees and seven programs
  reach the droppable lowerings below.

- `par` (`el_par.loft`): a vector source, a worker function named at the call, the wide-scalar
  and text lanes, the empty-body discard; the rest refused by name.  A text body is typed with
  the declared result as pass 2 met it (`block_result`'s `result`).

- Lambdas that capture nothing (`fn(…) -> R { … }`, `__lambda_<fn>_<N>`, their buffer
  reserved between the passes); a capture and the `|x|` spelling are refused by name.
- Function values: `fn(…) -> R` types, a function's name as its definition number, calls
  through a local (`NdCallRef`).  A text answered through one and a closure-carrying one are
  refused by name.
- A match on a plain struct (`struct_match`): bindings, renames, literal / `|` / range
  sub-patterns, guards, alternatives binding the same names.
- Pointer fields (`reference<T>` in a struct): the marker type, always nullable, the `dbref`
  rows, `OpGetDbRef` / `OpSetDbRef`, null and omitted fields; a vector of a linked record
  (`array<T>`, @C145) refused by name.  A field of a `S?` record reads as `τ?` unless an
  (N-Guard) test proved it present (`vars.present`); a `match` of records merges its arms'
  borrows.
