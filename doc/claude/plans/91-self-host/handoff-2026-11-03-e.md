## Ported this session (elaborator)

- **A call that leaves out a defaulted parameter** (`sum(v)`, `init: T? = null`): the missing
  slots take the parameter's default from the image, or null for a nullable one
  (`add_defaults`' general arm).  Refused by name: a default that reads another parameter, a
  call in a default that needs hidden parameters of its own, a link, a hidden buffer.
- **`o.s += t` on a text field** (`assign_var_nr`'s text arm): a `_field_N` local takes the
  field's text before the value is read, the value is appended as it is (a formatted text is
  NOT flattened, unlike a local), and it is written back with `OpSetTextReplace`.  A non-text
  value is refused by name.
