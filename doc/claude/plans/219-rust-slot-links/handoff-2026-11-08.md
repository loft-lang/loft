## Lessons

- **The bench checkouts must track what `libs.tsv` names.**  graphics, core, plugins and world sat
  on a stale `laptop-perf-bench` branch, so the canvas number of 2026-11-07 measured an old library
  (and random did not build on C).  `bench/portal/checkout_libs.sh --status` says where each stands;
  it never switches branches itself.
- **Read the probe's contract before building for the ship lane.**  `(R-StickySum)` and
  `(R-SpecChain)` were applied under the probe, where `+`/`-` wrap anyway: they made the ship lane
  answer null for overflows it wraps everywhere else, at a cost.
- **A hand-form script that edits a function must anchor on the DEFINITION line** (`… {`), not the
  first match — the prototype comes first and the edit silently lands nowhere.
- **Machine state moves ratios by ±20 % for minutes at a time.**  Trust `ab.py`'s alternation;
  re-run a surprising result head-to-head (two loft builds) before acting on it.
- **The emission pins and audits catch what the value tests do not**: `iteration_base` (counted
  steps), `extraction_hygiene` (layering), `quality_optional_table_matches_the_audit` (a type
  shape asked without peeling `τ?`).
