## Lessons from today

- Read `formal/performance.md` BEFORE choosing a metric: `(Perf-Weight)` already said cship.
  `stats.py`'s default `--lanes native,rust` measures the shelved Rust generator — name lanes
  (owner asked whether to change the default; not changed yet).

  overflow whose wrap misses the sentinel (GUARDS.md).

  chain-guard hoist added nothing — building only the half that paid saved a large change.
