pub fn parse(ps: text) -> integer?

Parse an ISO date "YYYY-MM-DD", optionally followed by " HH:MM[:SS]" or "THH:MM[:SS]" with an optional trailing "Z".

Null (test with !result) means the text is not SHAPED like a date — too short, or a non-digit where a digit belongs. It never means the date is not real: out-of-range fields ROLL OVER, so "2026-13-45" answers 2027-02-14 and "2026-02-30" answers 2026-03-02, both non-null. To reject an impossible date, round-trip it through format_date.
