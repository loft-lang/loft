pub fn http_get_range(url: text, offset: integer, len: integer) -> HttpResponse

Read the byte range [offset, offset+len) of a remote file via a Range request. Returns status 206 (Partial Content) with the raw bytes in body when the server honours ranges; a server that ignores Range returns 200 with the full body. Read the bytes with byte_at(response.body, i).

pub fn http_size(url: text) -> integer

Resolve a URL's total byte size without downloading it. Tries a HEAD request (Content-Length); if the server omits the length on HEAD (some CDNs — e.g. github-raw — only report it on GET), falls back to a 1-byte range read and takes the total from the Content-Range header. Returns -1 if size is unavailable.

pub struct WsHandler
pub fn ws_handler(url: text) -> WsHandler?

Open a WebSocket session. Returns null only if the URL is malformed; transient connection failures (server not yet up, network blip) are absorbed by the auto-reconnect loop in the Rust layer, so this call always returns a usable handle for any well-formed ws://... or wss://... URL.

wss:// (TLS) works on BOTH targets: the browser uses the platform WebSocket (which has always spoken wss), and since web 0.3.2 the native client dials TLS through rustls with certificate validation ON by default (default port 443). For a self-signed dev endpoint, set LOFT_WS_INSECURE_SKIP_VERIFY=1 in the native process — an explicit opt-out, never a URL option, so it cannot be baked into a deployed config by accident.

⚠ The return is WsHandler? and not WsHandler, because null is the whole point of the call: it is the one distinction this function exists to make. It used to be declared non-null, which meant the compiler called the == null test the contract asks for redundant — the signature denied the only thing it had to say.

pub fn send(self: WsHandler, msg: text) -> boolean

Send a text message to the server. Returns true on success; false means the connection is currently in backoff / reconnecting and the caller may retry after the next pump().

pub fn send_binary(self: WsHandler, msg: text) -> boolean

Send msg as a binary WebSocket frame (opcode 2). Loft text is a byte buffer — pack u8/u16/i32/etc. into it via to_bytes style code, then ship it. Returns true on success; false means the connection is currently in backoff / reconnecting.

pub fn last_opcode(self: WsHandler) -> integer

Opcode of the last frame surfaced by try_recv / pump on this handler. Use after a successful read to decide whether to interpret the payload as utf-8 text or as a binary blob.

pub fn pump(self: WsHandler, on_message: fn(text)) -> integer

Drain any pending received messages, firing on_message for each. Returns the count of messages delivered this call. Call this from a main loop (and yield to the host between iterations on the browser target) to drive event delivery without async.

pub fn try_recv(self: WsHandler) -> text?

Non-blocking single-message receive. Returns the next pending message text if one is available, null otherwise. Equivalent to a single iteration of pump without the callback — useful when the receiver wants to drive its own loop and accumulate messages locally without capturing state inside a closure.

pub fn close(self: WsHandler)

Permanently close the session (no further reconnect attempts).

pub fn sleep_ms(ms: integer)

Block the calling thread for ms milliseconds. Convenience for tests and pacing loops; non-positive values are a no-op. Not available on the WASM target — the host event loop is the equivalent.

pub fn pack_reset()

Empty the per-thread pack buffer. Call before each blob.

pub fn pack_u8(b: integer)

Append a single byte to the pack buffer. b is masked to 8 bits.

pub fn pack_u16_le(v: integer)

Append a 2-byte little-endian unsigned value.

pub fn pack_u32_le(v: integer)

Append a 4-byte little-endian unsigned value. Loft integer is i32 — bit-cast to u32 to preserve the LE byte pattern across the sign boundary.

pub fn pack_take() -> text

Take the contents of the pack buffer and return them as a text whose UTF-8 bytes are exactly the buffer bytes. Resets the buffer.

pub fn byte_at(idx: integer, t: text) -> integer

Read the byte at idx of the text payload. Out-of-range (negative or past the end) returns -1. Use to decode binary frames received via try_recv / pump. Argument order is (idx, t) — the C-ABI auto-marshal in src/extensions.rs supports (I32, Text) -> I32 but not (Text, I32) -> I32.
