gpu API

← gpu · version 0.1.0

62 public items, in source order. Generated from the registry index, which re-derives them from the package source at publish time — so a signature here is the one that version actually ships.

pub fn f4s(count: integer) -> integer

A block field that is an array of count F4s.

pub fn blend(source: integer, destination: integer) -> integer

A draw is combined with what the target holds: its colour times source, plus the target's times destination. blend(SRC_ALPHA, ONE_MINUS_SRC_ALPHA) is plain transparency.

pub struct Source { tag: text, vertex: text, fragment: text }

A shader's text in one shading language. tag names the language as a backend spells it (its README says which it takes); this library compares the tag and never reads it.

pub fn source(tag: text, vertex: text, fragment: text) -> Source

A source for the backend whose shading language is tag.

pub struct Program { vertex: vector<integer>, instance: vector<integer>, block: vector<integer>, textures: integer, sources: vector<Source> }

A shader set: what the shader reads, and its text for each backend it may meet.

pub struct State { shape: integer = 0, depth: integer = 0, blend: integer = 0, cull: integer = 0, into: integer = 0 }

Render state: fixed for a pipeline's life, so two states are two pipelines.

pub fn layout(block: const vector<integer>) -> vector<integer>

Where each field of a block starts, in floats, with the block's whole size as the last entry. Each field starts on the next multiple of its own size (a matrix and an array on 4 floats) and the size is rounded up to 4 — the layout every backend's shading language gives these field kinds, so a program reads the same bytes on each.

pub struct Device { handle: integer, pass: integer, pipe: integer, need_block: integer, need_textures: integer, sampled: integer, has_block: boolean, has_vertices: boolean, has_indices: boolean, has_instances: boolean, pipe_instances: boolean, refused: vector<text> }

One window (a page's canvas) and its GPU. Everything made from it is freed when it closes.

pub fn open(table: integer, width: integer, height: integer, title: text) -> Device?

Open a window of width x height pixels through the backend whose table is table (a backend library's table()). Null when the table is none — its stack is absent on this machine — or the window does not open. A game does not call this: its host package asks each backend in turn.

pub fn backend_name() -> text

The backend's own name, for a message. Never branch on it: ask what the machine has.

pub fn poll(self: const Device) -> boolean

Hand the machine's events to the window; false once it was closed.

pub fn width(self: const Device) -> integer

The window's width in pixels, as it is now.

pub fn height(self: const Device) -> integer

And its height.

pub fn close(self: Device)

Close the window and free everything made from it.

pub fn refusals(self: const Device) -> vector<text>

What was refused so far, oldest first: one line a call, saying which call and why. Empty for a program that keeps the rule.

pub struct Buffer { handle: integer, size: integer }

Floats on the GPU: vertices, or the values of drawn copies.

pub fn buffer(self: const Device, data: const vector<single>) -> Buffer

Upload data for a pipeline to read as vertices (vertices) or per copy (instances).

pub fn update(self: Buffer, data: const vector<single>)

Replace the floats; the length may change. For data that changes every frame.

pub fn floats(self: const Buffer) -> integer

How many floats it holds.

pub struct IndexBuffer { handle: integer, size: integer }

Vertex numbers on the GPU, for draw_indexed.

pub fn index_buffer(self: const Device, list: const vector<integer>) -> IndexBuffer

Upload a list of vertex numbers.

pub fn count(self: const IndexBuffer) -> integer

How many vertex numbers it holds.

pub struct Texture { handle: integer, w: integer, h: integer, depth: boolean }

An image on the GPU: colour (red, green, blue, alpha at 8 bits each) or depth.

pub fn texture(self: const Device, width: integer, height: integer) -> Texture

An empty colour texture, sampled between its pixels and clamped at its edges.

pub fn depth_texture(self: const Device, width: integer, height: integer) -> Texture

An empty depth texture: the depth of a target, or a shadow map.

pub fn texture_from(self: const Device, pixels: const vector<u32>, width: integer, height: integer) -> Texture

A colour texture holding pixels (0xAARRGGBB each, width to a row). Its first pixel is texture coordinate (0, 0).

pub fn put(self: const Texture, x: integer, y: integer, pixels: const vector<u32>, width: integer, height: integer)

Replace the width x height pixels at (x, y), counted from the texture's first pixel.

pub fn nearest(self: const Texture, on: boolean)

Sample the nearest pixel (pixel art), or between pixels (how a texture starts).

pub fn mipmaps(self: const Texture)

Build smaller copies from the pixels it holds now and sample through them when it is drawn small; call again after put.

pub fn width(self: const Texture) -> integer

Its width in pixels.

pub fn height(self: const Texture) -> integer

And its height.

pub struct Target { handle: integer, into: integer }

What a pass draws into other than the window. Its textures stay usable after it is gone.

pub fn colour_target(self: const Device, colour: const Texture) -> Target

A target of one colour texture.

pub fn target(self: const Device, colour: const Texture, depth: const Texture) -> Target

A target of a colour and a depth texture of one size.

pub fn depth_target(self: const Device, depth: const Texture) -> Target

A target of a depth texture alone: no colour is drawn.

pub struct Pipeline { handle: integer, into: integer, textures: integer, instances: boolean, fields: vector<integer>, starts: vector<integer> }

A program, its inputs and its render state, built for one kind of target.

pub fn pipeline(self: const Device, program: const Program, state: const State) -> Pipeline?

Build a pipeline: program drawn with state. Null when the program has no source for this backend, declares what a block cannot hold, or does not compile — the backend says why on stderr.

pub struct Block { data: vector<single>, fields: vector<integer>, starts: vector<integer>, wrong: integer }

The values of a pipeline's uniform block. A field is named by its position in the program's block list. Setting a field as another kind than it was declared, or one that is not there, marks the block, and uniforms then refuses it.

pub fn block(self: const Pipeline) -> Block

A block for this pipeline, every field zero.

pub fn f4_at(self: Block, field: integer, index: integer, x: float, y: float, z: float, w: float)
