Declare thing thing: how many height steps it adds to its stack, whether it blocks a cell for walking (passable, shortest_path), whether it stops sight and light, whether it gives light (a torch), and its glyph in view.

Declare edge kind kind (1..255): whether it can be walked across (an open doorway) and whether it stops sight and light (a wall, a closed door; not a fence or a window), and its glyph.

Set a cell's terrain: a kind (0..15) and, for the picture, a tile number (0..4095). VOID makes the cell void even on a layer with a ground — a pit, a hole; clear unsets it.

Give layer z a ground: every cell of it nobody set reads as terrain kind with picture tile — open land that costs no memory. Kind VOID takes the ground away.

Put edge kind kind (1..255) on side (NORTH, EAST, SOUTH, WEST) of cell (x, y, z); 0 takes the edge away. The east edge of a cell is its east neighbour's west edge, and the same edge: setting one sets both.

The edge kind on side of cell (x, y, z), 0 for none.

Can a walker step from (x, y, z) by (dx, dy) — one of the four directions — across the edge between: no edge, or one declared walkable. Whether the cell it lands on can be stood on is passable's question.

Do sight and light pass from (x, y, z) by (dx, dy) across the edge between.

pub fn set_rise(w: World, x: integer, y: integer, z: integer, steps: integer)

Give cell (x, y, z) a rise of steps (0..15): its own height, under whatever stands on it. A hillside is cells rising one step at a time, so a walker that steps up one at a time walks up it.

pub fn rise(w: const World, x: integer, y: integer, z: integer) -> integer

A cell's rise in steps, 0 for a flat one.

pub fn open_sky(w: const World, x: integer, y: integer, z: integer) -> boolean

Is (x, y, z) under the open sky: nothing set on the layer above it.

Put a thing on top of a cell's stack.

Take the top thing off a cell's stack and answer it; 0 when the cell has none. The stack goes when it empties.

The things on a cell, bottom first.

The top thing on a cell, 0 when there is none.

The height of a cell in steps: its rise and the declared heights of the things on it.

Can a cell be walked into: walkable terrain and nothing on it that blocks.

pub fn opaque(w: const World, x: integer, y: integer, z: integer) -> boolean

Does a cell stop sight and light: opaque terrain, or an opaque thing on it. An undeclared terrain kind (not void) is opaque.

pub fn lit(w: const World, x: integer, y: integer, z: integer, daylight: boolean = true) -> boolean

Does a cell give light: under the open sky (by day: daylight, the default), lit terrain, or a lit thing on it. A void cell gives none.

pub fn shortest_path(w: const World, x0: integer, y0: integer, x1: integer, y1: integer, z: integer, limit: integer = 64) -> vector<(integer, integer)>

The shortest walk from (x0, y0) to (x1, y1) on layer z, in steps to the four neighbours over passable cells and crossable edges: the cells passed through, the goal last, the start left out. Empty when the goal cannot be reached within limit steps (or is the start). The goal itself need not be passable, so a path can lead up to a thing to act on.

pub fn line_of_sight(w: const World, x0: integer, y0: integer, x1: integer, y1: integer, z: integer) -> boolean

Can (x1, y1) be seen from (x0, y0) on layer z: no opaque cell on the straight line between them (Bresenham's), and no opaque edge it crosses. The two ends themselves do not count, so a wall is seen, and an eye in a doorway sees out.

pub fn shades(w: const World, x0: integer, y0: integer, x1: integer, y1: integer, z: integer, lights: const vector<(integer, integer)> = [], start: const vector<integer> = [], daylight: boolean = true) -> vector<integer>

How dark each cell of (x0, y0) .. (x1, y1) on layer z is, row by row: 0 at a light, one shade darker for each step from the nearest one, up to DARKEST, never black. A light is a lit cell or one of lights (cells the game says give light now: what a figure carries, a torch). A light of lights starts at its shade in start (0, the default, is full; a dimmer light — a torch burning down — reaches less far), the k-th entry for the k-th light. Light spreads over every cell but an opaque one, which is lit but passes no light on unless it is itself a light, and never across an opaque edge. A light up to DARKEST cells outside the rectangle counts. daylight false: the open sky is no light — night, when only what gives light of itself (a lamp, a lit terrain) and lights light the world.

pub fn view(w: const World, x0: integer, y0: integer, x1: integer, y1: integer, z: integer, marks: const vector<(integer, integer, text)> = []) -> text

A layer as text, one line per row: each cell's top thing's glyph, or its terrain's, or a space for void. marks puts a glyph of the game's at a cell (a figure): (x, y, glyph).

pub fn region(w: const World, x: integer, y: integer, z: integer, limit: integer) -> vector<(integer, integer)>

The cells of layer z connected to (x, y) that hold the same terrain as it — the same kind and tile, set or read from the ground — four ways, never across an edge between two cells: what a fill paints. Nearest first (breadth first), (x, y) itself first, and at most limit of them, because a layer's ground has no end: a region exactly limit long may go on.

pub fn copy(w: const World, x0: integer, y0: integer, x1: integer, y1: integer, z0: integer, z1: integer) -> World

A stamp: the cells of the box x0..x1, y0..y1 on layers z0..z1, corners included — terrain as set (an unset cell stays unset), rise, the north and west edges each cell holds, and the stacks — moved so the corner (x0, y0, z0) is (0, 0, 0). The kinds come along: the stamp is a world of its own, to paste back or keep.

pub fn paste(w: World, from: const World, x: integer, y: integer, z: integer)

Write stamp from (a copy) into w with its (0, 0, 0) at (x, y, z). Each cell the stamp holds anything at replaces the cell there: its terrain when the stamp set it, its rise and north and west edges, and its stack (none when the stamp's cell has none). A cell the stamp holds nothing at leaves w as it was.
