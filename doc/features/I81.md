# @I81 — Feature-catalogue sync generator (issues → in-project mirror + example tests)

## What it does

Keeps the in-project copy of the feature catalogue in step with this issue tracker. It reads a committed snapshot of the issues and regenerates, one-way, a browsable mirror of every entry plus a runnable test file for each feature's example. Agents and CI then work from the issues without anything being written down twice: the issue is the single source, and two guards keep the copy honest — one fails if the mirror drifts from the snapshot, the other fails if any extracted example stops running.

## Where it lives

`tools/features/gen.loft` (the generator), the `Makefile` targets `features-fetch` / `features-gen` / `features-check`, and the example-runs guards in `tests/features.rs` (interpret) and `tests/native.rs::native_features` (native). Realizes strand 3 of @PLN92.
