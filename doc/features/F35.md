# @F35 — String literals — `{expr}` interpolation + backtick multiline

## What it is

Text can carry values directly: write `{expr}` inside a string and its value is dropped in place. A brace you want to KEEP is doubled — `{{` and `}}` produce a literal `{` and `}` — which is the one thing to know before writing CSS, JSON or a shell snippet inside a string.

Strings in backticks may also span several lines, so the text you write looks like the text you get — including the indentation you gave it to fit the surrounding code.

## How it aids you

Building messages stays simple and readable — no clumsy joining of pieces with `+`. And multi-line strings let you lay out an email, a template, or a block of output exactly as it should appear.

**Indentation is handled for you.** A backtick block is dedented against its **first content line**: however many leading spaces that line has come off every line that has them. A line indented less than that base comes out flush, a deeper line keeps the difference, and the first and last lines are dropped when they hold only whitespace — so a shader or a config block written at whatever indent its surrounding code sits at comes out at column 0, with its own inner structure intact.

**Interpolation is no exception**: a block with `{expr}` in it dedents exactly like one without. Until loft#990 a single hole anywhere switched the strip off entirely and kept the trailing blank line as well, which meant the dedent served the block with no values in it and silently stopped serving the template — the shape the feature exists for. One edge remains, and it is silent: a TAB-indented line is never dedented, because a tab is not a space and there is nothing to count.

## Example

```loft
fn main() {
    name: text = "world";
    n: integer = 3;
    println("Hello, {name}. You have {n} messages.");
    note: text = `first line
second line mentions {name}`;
    println(note);
    println("a literal brace: {{ {n} }}");
}
// Output:
// Hello, world. You have 3 messages.
// first line
// second line mentions world
// a literal brace: { 3 }
```
