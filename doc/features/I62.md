# @I62 — IR data model (Value/Type/Data)

## What it does

Defines the core data types the whole compiler passes around: `Value` (an IR node), `Type` (a static type), and `Data` (the table of all named definitions). It is the shared vocabulary that the parser produces and every later stage consumes.

## Where it lives

`src/data.rs`
