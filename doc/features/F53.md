# @F53 — Native-binary backend (`--native` → rustc)

## What it is

The native backend. `loft --native prog.loft` translates your program to Rust and compiles it with `rustc` into a real machine-code binary, then runs it. It is already the default when you run `loft prog.loft`; `--ship` builds the program as you ship it — fully optimised, its native libraries linked in, and `--native-emit` writes out the generated Rust for you to keep.

## How it aids you

You get compiled-language speed from the same source you were interpreting, with no rewrite and no separate toolchain to wire up. Reach for `--ship` when you build the program you hand to someone, on any target (`--ship --native-wasm`, `--ship --html`), and use `--native-emit` when you want to see or reuse the Rust that loft produced.

## Example

```
$ loft --native prog.loft          # compile via rustc and run (this is the default)

$ loft --ship prog.loft            # the shipped build: fully optimised, libraries linked in

$ loft --native-emit prog.loft     # write the generated Rust and exit (no run)
```
