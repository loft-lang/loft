# @I85 — Engine-host kernel natives

## What it does

The set of low-level host primitives the engine exposes to running loft code — the kernel-level mechanisms, beyond ordinary stdlib functions, that let a program reach into the engine itself. It is the controlled boundary between loft-level code and the host runtime's internals.

## Where it lives

`src/engine_host.rs` (the `n_kernel_*` natives, both backends); the typed loft surface is
`lib/engine_host/`, which declares them `#native` and wraps the raw pump into `run` /
`run_client`, `send` / `broadcast` and the sync lanes.

First consumers: the audience demos CI spawns — `tools/audience-demo/server_kernel.loft` and
`tools/audience-demo-50/probe_server_kernel.loft` / `probe_client_kernel.loft`.

## In real use

Where this feature carries real work, validated by `check_doc_drift.sh examples`:

Example: @EHK-001 — `run(port, tick_us, on_event, on_tick)` IS the server loop, with the handlers passed as closures
Example: @EHK-002 — `broadcast` to every client against `send` to one, replaying state to a client that just connected
Example: @EHK-003 — a fast lane is declared BEFORE `run`, not during it
Example: @EHK-004 — the client side: `run_client` plus the `client_sync_next` / `client_sync_payload` drain loop
