# @F48 — The `loft` CLI — run a program, `--interpret` / `--native`, `--timeout`, `--help`

## What it is

The `loft` command runs a program written in loft. Point it at a source file and it compiles and runs the program in one step. By default it builds a fast native binary; `--interpret` runs the program through the built-in interpreter instead. `--timeout` caps how long a run may take, and `--help` lists everything the command can do.

## How it aids you

One command takes you from a `.loft` file to a running program — there is no separate build or install step to manage. You switch between the quick-starting interpreter and the faster native build with a single flag, and `--timeout` stops a runaway program instead of letting it tie up your terminal.

## Example

```
$ loft hello.loft                 # compile and run (native backend, the default)
Hello, world!

$ loft --interpret hello.loft     # run through the interpreter instead
Hello, world!

$ loft --timeout 60 slow.loft     # hard-kill the run after 60 seconds (0 = no limit)

$ loft --help                     # list every option and subcommand
```

A running loft program cannot invoke a command, so the citation below pins the **artefact** instead — the record this tool emits or reads, captured verbatim from a real run, so that a change to the shape a client depends on breaks a test rather than a client. That the command itself runs is guarded by the binary's own Rust suite.
