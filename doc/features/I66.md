# @I66 — Bytecode VM / executor

## What it does

The virtual machine that runs the compiled bytecode: it holds the instruction stream and the runtime stack and drives the main execute loop that steps through opcodes. This is the engine of the interpreter backend.

## Where it lives

`src/state/mod.rs` (the `State` type and its execute loop)
