# @F34 — Coroutines / generators — `yield`, `yield from`

## What it is

A generator is a function whose return type is `iterator<T>`. Instead of building a whole list up front, it hands back values one at a time with `yield`, pausing after each and resuming where it left off when the next value is asked for.

## How it aids you

You get a stream of values on demand — computed only as far as you actually consume it — and you drive it with the same `for` loop you use for any collection, with no intermediate list held in memory.

## Example

```loft
// A generator: its return type is iterator<T>, and it produces
// values one at a time with yield.
fn count_up(start: integer, stop: integer) -> iterator<integer> {
    for i in start..stop {
        yield i;
    }
}

fn main() {
    for n in count_up(1, 4) {
        println("{n}");   // 1, then 2, then 3
    }
}
```
