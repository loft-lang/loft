# @F8 — `sorted<T[keys]>` collection

## What it is

A collection of records that stays in sorted order by a key field you choose. New records drop into the right position on their own, and looping over the collection visits them in that order. A leading `-` on the key means order it the other way round.

## How it aids you

You never have to re-sort by hand. Add records whenever you like and the collection is always in order — ideal for leaderboards, rankings, or anything you want to read back highest-first or lowest-first.

## Example

```loft
struct Item { name: text, score: integer }
struct Board { items: sorted<Item[-score]> }
fn main() {
    b = Board { items: [
        Item { name: "Ada", score: 30 },
        Item { name: "Bo", score: 90 },
        Item { name: "Cy", score: 60 }
    ] };
    for it in b.items {
        println("{it.name}: {it.score}");
    }
    // Bo: 90
    // Cy: 60
    // Ada: 30
}
```
