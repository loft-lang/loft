# @F6 — `vector<T>` — append, index, slice, comprehensions, aggregates, map/filter/reduce

## What it is

A growable list of values of one type. Add to it with `+=`, read an item by position (`v[0]`), ask its length with `len(v)`, and build a new list from an existing one with a comprehension.

## How it aids you

It is the go-to container for "a bunch of things" — a list you grow as you go and transform in a single line, without keeping track of the size yourself.

## Example

```loft
fn main() {
    v: vector<integer> = [1, 2, 3];
    v += [4];                              // grow
    doubled = [for x in v { x * 2 }];      // build a new list from it
    println("first={v[0]} len={len(v)} doubled_first={doubled[0]}");
    // first=1 len=4 doubled_first=2
    middle = v[1..3];                      // a slice: elements 1 and 2, the end excluded
    tail = v[2..];                         // from element 2 to the end
    println("{middle} {tail} {v[..2]}");   // [2,3] [3,4] [1,2]
}
```
