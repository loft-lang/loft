# @F52 — Source formatter — canonical `.loft` output

## What it is

A built-in source formatter. `loft --format file.loft` rewrites the file in canonical loft style in place; `loft --format-check file.loft` leaves the file alone and just exits non-zero if it is not already formatted. `loft --format -` reads from standard input and writes the result to standard output.

## How it aids you

Everyone's loft looks the same, so you never argue about spacing or indentation and diffs stay small and meaningful. `--format-check` plugs into a commit hook or CI to keep a whole project consistent automatically, and the `-` form lets an editor format a file or selection on demand.

## Example

```
$ loft --format main.loft          # reformat the file in place

$ loft --format-check main.loft    # exit 1 if it is not already canonical (for CI)

$ cat main.loft | loft --format -  # format from stdin to stdout
```
