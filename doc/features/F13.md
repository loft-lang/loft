# @F13 — Simple enums (ordered value types)

## What it is

A type that is exactly one of a fixed set of named options.

## How it aids you

When something can only be one of a few choices, an enum names them all in one place — you can't use an invalid value, and a `match` can make sure you have handled every case.

## Example

```loft
enum Direction { North, East, South, West }
fn main() {
    d: Direction = East;
    label = match d { North | South => "vertical", East | West => "horizontal" };
    println(label);    // horizontal
}
```
