# @F54 — Browser / WASM target (`--html` / `--native-wasm`)

## What it is

The browser target. `loft --html prog.loft` compiles your program to WebAssembly and bundles it into a single self-contained HTML file you can open in any browser. `loft --native-wasm prog.loft` emits just the `.wasm` module when you want to embed it yourself.

## How it aids you

The same loft program that runs on your machine can run on a web page, with nothing to install for whoever opens it — one HTML file is the whole deliverable. It is the simplest way to share a demo, a tool, or a game that people can try with a single click.

## Example

```
$ loft --html game.loft            # write a self-contained game.html
$ # open game.html in a browser — no server or install needed

$ loft --native-wasm game.loft     # emit just game.wasm to embed yourself
```

## What a page can carry

The single file is not limited to code. Three declarations in `loft.toml` put content on
the page, and each has a native counterpart so the same source runs both ways:

* `[[font]]` — the page draws with the font you name rather than a fallback. Declare a
  family the browser already has (nothing is downloaded), a `url` to your own server, or
  a provider `stylesheet`; `--html` emits the `@font-face` or `<link>` and awaits
  `document.fonts.load` before the program starts, so the first frame is not drawn in the
  wrong font.
* `[[embed]]` — a file seeded into the page's own filesystem, which is how a game carries
  an asset pack and reads it with one `store_load` call on the desktop and in the browser
  alike. For a pack too large to embed, the same store is read over HTTP range from any
  static file host — see @F93.
* **Audio** — a browser page loads, plays, loops, pans and seeks sampled sound, the way a
  desktop build does.

A running loft program cannot invoke a command, so the citation below pins the **artefact** instead — the record this tool emits or reads, captured verbatim from a real run, so that a change to the shape a client depends on breaks a test rather than a client. That the command itself runs is guarded by the binary's own Rust suite.
