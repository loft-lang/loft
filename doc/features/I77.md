# @I77 — Registry / manifest / lockfile resolution

## What it does

Resolves package dependencies for the package manager: it reads each project's manifest (`loft.toml`), consults the registry, and computes the lockfile that pins exact versions. It is the dependency-resolution brain behind `loft install`.
