# @F56 — Live code reload — patch a running program

## What it is

Live code reload. With reload enabled, loft watches your source file while the program runs and swaps in edited functions on the fly, so your changes take effect without stopping and restarting the program. It is opt-in via the `LOFT_LIVE_RELOAD` setting.

## How it aids you

You keep the program's current state — the game you are part-way through, the data you loaded, the window you opened — and still see code edits apply immediately. That tightens the edit-and-see loop and removes the restart-and-get-back-to-where-you-were tax when you are iterating on behaviour.

## Example

```
$ LOFT_LIVE_RELOAD=1 loft game.loft
# the program keeps running; edit and save game.loft in your editor…
# …the changed functions are hot-swapped into the live program automatically
```

A running loft program cannot invoke a command, so the citation below pins the **artefact** instead — the record this tool emits or reads, captured verbatim from a real run, so that a change to the shape a client depends on breaks a test rather than a client. That the command itself runs is guarded by the binary's own Rust suite.
