# @F118 — Time (now / ticks)

## What it is

Two clocks, for the two questions a program asks about time.

`now()` answers the wall clock: milliseconds since the Unix epoch. It is the one to stamp a
record with, or to compare against a date someone else wrote down.

`ticks()` answers elapsed time: microseconds from an arbitrary start, and it only ever goes
forward. It is the one to measure with — subtract two readings and you have a duration.

They are not interchangeable. A wall clock can jump backwards when the machine syncs its
time, so a duration measured with `now()` can come out negative; `ticks()` cannot do that,
and it has a thousand times the resolution.

## How it aids you

Stamp events with `now()` so they mean the same thing to another program, on another machine,
next year. Time your own code with `ticks()` — a frame, a request, a slow loop — and get an
answer that does not depend on what the clock did while you were measuring.

## Example

```loft
fn main() {
    started = ticks();                      // microseconds, monotonic
    total = 0;
    for i in 0..100000 { total += i; }
    elapsed = ticks() - started;
    println("sum: {total}");                          // sum: 4999950000
    println("measured a duration: {elapsed >= 0}");   // measured a duration: true
    println("clock is set: {now() > 0}");             // clock is set: true
}
```
