# @F41 — Environment & arguments (env vars, arguments(), program dirs, path resolution)

## What it is

Read the settings the program was started with: environment variables via `env_variable(name)`, and the extra words typed after the program name on the command line via `arguments()`.

## How it aids you

Let the outside world shape a run without editing code — a value from the environment, a filename or option passed on the command line — so the same program adapts to each invocation.

## Example

```loft
fn main() {
    // run with:  GREET_NAME=world  loft greet.loft
    name = env_variable("GREET_NAME");
    println("hello, {name}");                         // hello, world
    println("extra arguments: {arguments().len()}");  // extra arguments: 0
}
```
