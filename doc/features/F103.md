# @F103 — `deliver` / `expose` — hand a loft value to JavaScript with no copy

## What it is

`deliver` hands a whole loft value — a record, a vector, nested to any depth — to JavaScript in the browser with **no serialisation and no copy**. JavaScript reads it straight out of WebAssembly memory, guided by a layout description loft sends along with it. `expose` keeps a value readable across frames; `release` lets it go.

## How it aids you

The usual cost of getting data out of WebAssembly is converting it to JSON and parsing it on the other side, which is both slow and a second description of your types to keep in sync. This removes both: a scalar vector arrives as a typed-array view over the same bytes, so handing over a million numbers costs the same as handing over one.

## Example

```js
// In the page: read the value the loft program delivered.
const value = readLoftValue(tag);
console.log(value.points.length);   // a typed-array view, not a copy
```

Keyed collections (hash, index, sorted, spatial) are flattened to arrays at delivery, so the reader only ever sees scalars, text, records, vectors and enums.
