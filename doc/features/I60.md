# @I60 — Scope & dependency/lifetime tracker (deps)

## What it does

Tracks which names are visible in each scope and follows how values borrow from and depend on one another, so the compiler knows when each value can safely be freed. This dependency ("deps") information is the backbone of loft's ownership and memory-safety model.

## Where it lives

`src/scopes.rs`
