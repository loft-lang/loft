# @F23 — Function references as first-class values

## What it is

A function's name can be used as a value all by itself. Store it in a variable, pass it to another function, or keep it for later — all without the parentheses that would run it right away.

## How it aids you

Choose behaviour while your program is running and pass it around like any other value: pick which action to apply, or hand a function to a helper like `map` to run over your data. Your code gets to decide not just what data to use but which action to take.

A function value goes anywhere a value goes — a local, a vector element, a struct field, an argument — and a lambda that captured something goes there too. Taking a behaviour as a PARAMETER is how a library stays honest about what it does not own: an engine that asks for its measurement function cannot secretly depend on a font, and a kernel that asks for its event handler cannot depend on your game.

## Example

```loft
fn double(x: integer) -> integer {
    x * 2
}
fn twice(f: fn(integer) -> integer, x: integer) -> integer {
    f(f(x))                            // a parameter whose type is a function
}
fn main() {
    f = double;
    println("f(21) = {f(21)}");        // f(21) = 42
    doubled = map([1, 2, 3], double);
    println("{doubled}");              // [2,4,6]
    g: fn(integer) -> integer = double;   // the type, spelled out
    println("{twice(g, 5)}");          // 20
}
```
