# @I59 — Type resolver

## What it does

Resolves every type name to a concrete definition and works out each type's memory layout — its size and the byte offset of each field. This gives the rest of the compiler the fixed shapes it needs to lay out values and to generate field access.

## Where it lives

`src/typedef.rs`
