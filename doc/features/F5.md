# @F5 — Type conversions — implicit, format-only, and explicit `as`

## What it is

The `as` cast converts a value from one type to another on purpose: `pi as integer`, `"42" as integer?`, `'A' as integer`. You ask for the conversion, so it happens exactly where you write it.

What each cast does:

- **float → integer** truncates toward zero: `3.75 as integer` is 3, and `-3.75 as integer` is -3.
- **text → number** is a parse that can fail, so a bare `"42" as integer` is refused. Write `s as integer?` (null on a bad parse) or `s as integer ?? 0` (your fallback on a bad parse).
- **integer → narrow type** (`u8`, `i16`, a `limit` type): `n as u8` is refused unless the compiler can prove `n` fits. `n as u8?` is the checked cast: the value when it fits, null when it does not.
- **text → enum**: `s as Direction` reads a variant name at run time. A text that names no variant gives the first variant, and the compiler warns (`warning[enum-parse-default]`). Write `s as Direction?` to get null instead.
- **enum → integer**: variants number from 1, so `Direction.North as integer` is 1.
- **character → integer** gives the character's code: `'A' as integer` is 65.

Turning a value into text is not a cast: `7 as text` is refused. Write `"{x}"`.

## How it aids you

You get to move between types deliberately — drop the fraction of a decimal, read a number out of text, get a character's code — with the conversion visible in the code. Nothing silently changes type behind your back.

Whether a cast can REFUSE is the target type's choice, not the cast's. `"42" as integer?` has a null channel and answers null on rubbish; a cast to a type with no null — a `value struct` (@F95) — cannot, so it is total and bad input arrives as an ordinary-looking value of that type. Read the target's own documentation before treating a cast as a check.

## Example

```loft
fn main() {
    pi: float = 3.75;
    whole = pi as integer;      // 3  (drops the fraction)
    m: float = -3.75;
    neg = m as integer;         // -3 (toward zero, not down to -4)
    parsed = "42" as integer?;  // text turned into a number (or null)
    bad = "4x" as integer ?? 0; // 0  (a bad parse takes the fallback)
    code = 'A' as integer;      // 65 (the character's code)
    n = 400;
    small = n as u8?;           // null (400 does not fit a u8)
    println("{whole} {neg} {parsed} {bad} {code} {small}");   // 3 -3 42 0 65 null
}
```
