# @I87 — Auto-use / lazy library triggers

## What it does

Lets a program use a library's names without writing an explicit import. A lightweight pre-scan of the source works out which library each otherwise-unresolved name belongs to and arranges to load that library the first time the name is used. It keeps small programs terse while still resolving to exactly the right library.

## Where it lives

`src/libscan.rs` (the pre-scan), `src/triggers.rs` (per-library load triggers)
