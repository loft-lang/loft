# @F26 — Interfaces & bounded generics (`<T: A + B>`, operator interfaces)

## What it is

A bound like `<T: Ordered>` lets a generic function require that its type can do certain things — here, be compared with `<` and `>`. An interface names a group of abilities (Ordered for comparing, Addable for adding, and so on) that a type either has or does not.

## How it aids you

Write one function that works for every type that can be compared — numbers, text, and more — while Loft guarantees you only use abilities each type genuinely has. You get broad reuse without giving up the checks that catch mistakes early.

## Example

```loft
fn largest<T: Ordered>(a: T, b: T) -> T {
    if a > b { a } else { b }
}
fn main() {
    println("{largest(3, 7)}");        // 7
    println("{largest(2.5, 1.5)}");    // 2.5
    best = largest("apple", "pear");
    println(best);                     // pear
}
```

## The shipped interfaces

| interface | what the bound allows | a user type satisfies it by defining |
|---|---|---|
| `Ordered` | `<`, and `>`, `<=`, `>=` derived from it | `fn OpLt(self: T, other: T) -> boolean` |
| `Equatable` | `==` and `!=` | every type has it; `OpEq` replaces the default |
| `Addable` | `+` | `fn OpAdd(self: T, other: T) -> T` |
| `Subtractable` | binary `-` (`a - b`) | a two-parameter `fn OpMin(self: T, other: T) -> T` |
| `Numeric` | `*` and unary `-` (`-a`) | `OpMul`, and a one-parameter `OpMin` |
| `Scalable` | `x.scale(factor)` | `fn scale(self: T, factor: integer) -> integer` |
| `Printable` | formatting, `"{x}"` | `fn to_text(self: T) -> text` |

`integer`, `float` and `single` satisfy every one except `Scalable`, which only a type that defines `scale` has. `text` is `Ordered`, `Equatable` and `Printable`, but not `Addable`: `total("a", "b")` with `<T: Addable>` is refused (*"'text' does not satisfy interface 'Addable': missing OpAdd"*).

A type satisfies an interface just by having the functions — there is nothing to register. Combine bounds with `+`: `<T: Numeric + Subtractable>`.

You can declare your own interface:

```loft
interface Named {
    fn name(self: Self) -> text
}
fn greet<T: Named>(x: T) -> text { "hi {x.name()}" }
```

An interface is a bound on a type variable, not a type of its own: `x: Ordered = 3` or a parameter `p: Ordered` does not compile.
