# @F14 — Polymorphic struct-enums (per-variant fields)

## What it is

An enum whose choices each carry their own fields. One `Shape` type can be a `Circle` with a radius or a `Rect` with a width and height — every variant keeps exactly the data it needs.

## How it aids you

You keep a family of related shapes under one type, and you can give each variant its own version of a method. Calling `area()` runs the right one automatically, so your code stays simple no matter which variant it is holding.

The rules to know:

- Build a value with the enum name and the variant: `Shape::Circle { radius: 2.0 }`.
- A method called on a value typed as the enum (`Shape`) needs a body for every variant. If one is missing, the call is a compile error that names it (`not exhaustive — missing: Tri`). Write the missing method, or one fallback `fn area(self: Shape)` that every variant without its own method reaches (@F20).
- To reach a variant's fields, use `match` (`Circle { radius } => …`) or `is` with a capture (`if s is Rect { width } { … }`, @F30).

## Example

```loft
enum Shape {
    Circle { radius: float },
    Rect { width: float, height: float }
}
fn area(self: Circle) -> float { 3.14 * self.radius * self.radius }
fn area(self: Rect) -> float { self.width * self.height }
fn main() {
    shapes: vector<Shape> = [
        Shape::Circle { radius: 2.0 },
        Shape::Rect { width: 3.0, height: 4.0 }
    ];
    for s in shapes {
        println("area={s.area()}");      // area=12.56, then area=12
        match s {
            Circle { radius } => println("a circle of radius {radius}"),
            Rect { width, height } => println("a {width} by {height} rectangle")
        }
    }
}
```
