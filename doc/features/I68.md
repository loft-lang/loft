# @I68 — Native Rust generator

## What it does

The `--native` backend: translates the program's IR into Rust source code, which `rustc` then compiles into a fast standalone binary. It produces the same behaviour as the interpreter along a different, compile-to-machine-code path.

## Where it lives

`src/generation/` (entry point `src/generation/mod.rs`)
