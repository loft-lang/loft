# @F36 — String formatting / format specifiers (+ for-expressions)

## What it is

Inside `{...}` you can add a format after a colon to control how a value looks: pad it to a width, zero-fill it, fix the number of decimals, align it, or show it in hex, octal, or binary.

## How it aids you

You get tidy, aligned output — tables, reports, invoices, hex dumps — without hand-counting spaces or writing rounding code. The look of each value is described right next to it.

## Example

```loft
fn main() {
    n: integer = 255;
    pi: float = 3.14159;
    label: text = "hi";
    println("{n:#x} {n:05} {pi:6.2} {label:>6}");   // 0xff 00255   3.14     hi
}
```
