# @F27 — `if` / `else` as an expression

## What it is

`if` / `else` chooses between two branches — and it gives back a value, so you can assign the result directly.

## How it aids you

You set a variable to one thing or another in a single readable line, instead of declaring it first and reassigning it inside separate branches.

The rules to know:

- When the value is used, `else` is required: `kind = if x > 5 { "big" }` is refused, because there would be no value when the test fails.
- Both branches give one type. An integer branch beside a float branch widens to float; any other mismatch, such as `1` beside `"a"`, is refused.
- Chain more tests with `else if`.
- A name first bound inside a branch is gone after the block. `if c { label = "a"; } else { label = "b"; }` followed by a use of `label` is refused (`local-out-of-scope`). Bind the whole `if` instead: `label = if c { "a" } else { "b" };`.

## Example

```loft
fn main() {
    x = 7;
    kind = if x % 2 == 0 { "even" } else { "odd" };
    println(kind);    // odd
    size = if x < 0 { "negative" } else if x < 5 { "small" } else { "large" };
    println(size);    // large
}
```
