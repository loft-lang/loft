# @F44 — Logging & diagnostics API (log_*, print, assert, panic)

## What it is

The everyday ways a program reports what it is doing: `print` and `println` write to the screen, the `log_info` / `log_warn` / `log_error` family records diagnostic notes to a log, `assert(condition, message)` stops with a message if the condition is false, and `panic(message)` stops right away.

## How it aids you

See what your program is doing and catch bad states early — a printed line while you develop, a logged note in a finished tool, an assertion that fails loudly the moment an assumption breaks — instead of chasing a silent wrong answer later.

## Example

```loft
fn main() {
    print("loading");
    print("...");
    println(" done");              // loading... done
    log_info("startup complete");  // recorded to the log when logging is configured
    steps = 3;
    assert(steps > 0, "need at least one step");
    println("ran {steps} steps");  // ran 3 steps
}
```
