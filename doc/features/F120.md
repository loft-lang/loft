# @F120 — Lexer in loft (lib/lexer.loft) — part of the loft-in-loft front end, not a user library yet

## What it is

`lib/lexer.loft` is written in loft and lives in loft's own tree.  It is one of the first pieces of the
loft-in-loft front end — the self-hosting work — where the compiler's own lexer (@I57) is rewritten in loft
itself.  **It is not in the registry and is not a supported user library yet**: `loft install`
does not find it, and its interface changes with the front end it is being built for.

What it does today:

It breaks text into TOKENS — the smallest pieces that carry meaning:
numbers, names, operators, quoted strings.

You tell it two things about your language and it handles the rest. `set_tokens` lists the
multi-character operators, so `+=` is scanned as one token instead of a `+` and an `=`.
`set_keywords` lists the reserved words, so `let` comes back as itself and never as an
ordinary name.

Then you read tokens in order with typed readers: `int()` takes the next integer or answers
null, `identifier()` takes the next name, `matches(s)` takes the next token only if it is `s`
and says whether it did, `peek()` looks without taking.

⚠ **@I57 Lexer** is the lexer the compiler uses today, written in Rust; this file is its
loft rewrite, and the compiler does not use it yet.

## Where it lives

`lib/lexer.loft`, beside `lib/parser.loft` — the two front-end pieces of the self-hosting work that exist so far.  The example
below runs from loft's own tree, as the catalogue's example test.

## Example

```loft
use lexer;

fn main() {
    l = lexer::Lexer { };
    l.set_tokens(["+=", "==", "->"]);        // scanned as ONE token each
    l.set_keywords(["let", "in"]);           // reported as themselves, never as names

    l.parse_string("snippet", "let total += 12");
    println("keyword: {l.matches(\"let\")}");   // keyword: true
    println("name: {l.identifier()}");          // name: total
    println("operator: {l.matches(\"+=\")}");   // operator: true
    println("number: {l.int()}");               // number: 12
}
```
