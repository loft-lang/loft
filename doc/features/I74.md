# @I74 — CDylib extension loader

## What it does

Loads compiled native extension libraries (cdylibs) at runtime and connects their exported functions into the running program, letting a loft program call into prebuilt native code.

The same wiring serves the standard library itself: an interpreted program runs the stdlib's looping loft functions compiled, from a bridge table BUILT INTO the loft binary (`src/compiled_stdlib_gen.rs`), looked up before `dlsym` — so no rustc and no cdylib are needed at run time.  A program whose type prefix or stdlib source does not match runs the loft bodies interpreted instead (INTERPRETER_PERFORMANCE.md § The compiled standard library; `LOFT_NO_COMPILED_STDLIB=1` switches it off).

## Where it lives

`src/extensions.rs`
