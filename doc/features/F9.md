# @F9 — `index<T[keys]>` B-tree index (asc/desc, multi-key)

## What it is

A collection of records kept in order by one or more key fields. You can jump straight to a record by its keys, and you can also walk through a whole ordered range of them. A leading `-` on a key orders it the other way round.

## How it aids you

It combines instant lookup with ordered iteration over more than one field at once — group by a primary key, break ties with a second, and read the records back in order.

## Example

```loft
struct Row { group: integer, name: text }
struct Db { rows: index<Row[group, name]> }
fn main() {
    db = Db { rows: [
        Row { group: 2, name: "b" },
        Row { group: 1, name: "a" },
        Row { group: 1, name: "c" }
    ] };
    for r in db.rows {
        println("{r.group}-{r.name}");
    }
    println("lookup 1,a -> {db.rows[1, "a"].group}");
    // 1-a
    // 1-c
    // 2-b
    // lookup 1,a -> 1
}
```
