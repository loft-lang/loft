# @F105 — Custom `to_text` format hook — a type owns how it prints

## What it is

A type can decide how it prints. Define `operator to_text(self: T, spec: text) -> text` and `"{x}"` calls it; `"{x:anything}"` hands `anything` straight through, so the type owns its whole format vocabulary.

## How it aids you

Money, dates, colours and units print the way they should everywhere, once, instead of at every call site. And because the spec string is passed through untouched, the language never has to learn a date or currency vocabulary — your type defines what its own specs mean.

## Example

```loft
value struct Money { cents: integer }

operator to_text(self: Money, spec: text) -> text {
    whole = self.cents / 100;
    rest = self.cents % 100;
    out = if spec == "raw" { "{self.cents}" } else { "{whole}.{rest:02}" };
    out
}

fn main() {
    m = Money { cents: 1250 };
    println("{m}");        // 12.50
    println("{m:raw}");    // 1250
}
```

The companion hook is `fn OpConvTFromS(v: S) -> T`, which makes `s as T` work — together they let a library type behave like a built-in.
