# @F114 — A library type reads an element through a named method — `[…]` is the built-in collections'

## What it is

`[…]` belongs to the built-in collections — `vector`, `text`, the keyed collections.  A
library type reads an element through a NAMED method, `x.at(i)`, which the type defines
like any other: `x[i]` on a program's type is refused at compile time, naming that cure.
(Until loft 2026.11 a type could define `fn OpIndex` and be subscripted; C132 retired that
with every other `fn Op…`, @PLN182 Q10.)

The index type is whatever the method declares — a row addressed by column NAME takes a
`text` — and what a miss means is the TYPE's decision, not the language's.

## How it aids you

One spelling per meaning: a subscript is always a built-in collection's, so a reader never
has to look up whether `x[i]` is a vector read or a method with its own rules.  A wrapper
type says what its read does in the method's name and signature, and a bound can require
it like any method.

## Example

```loft
struct Ring {
    data: vector<integer>,
    start: integer,
}

// A ring's element read is whatever this says it is.
fn at(self: Ring, i: integer) -> integer {
    n = len(self.data);
    if n == 0 { return 0; }
    return self.data[(self.start + i) % n] ?? 0;
}

fn main() {
    r = Ring { data: [10, 20, 30], start: 1 };
    println("{r.at(0)} {r.at(1)} {r.at(2)}");    // 20 30 10
}
```

## A bound can require it

```loft
interface Indexable {
    fn at(self: Self, i: integer) -> integer
    fn count(self: Self) -> integer
}

fn total<I: Indexable>(x: I) -> integer {
    s = 0;
    for i in 0..x.count() { s += x.at(i); }
    return s;
}
```

An interface cannot require `[…]` (`op []` is refused where it is written): no type defines
it, so nothing could meet the member.

## What `x[i]` on a library type says

`` `Ring` cannot be indexed: `[…]` belongs to the built-in collections — give `Ring` a method
that reads an element, and call it `` — once per subscript, whatever is between the brackets
(`r[0]`, `m[r, c]`, `r[a..b]`, `r[0] = …`).  A function named `OpIndex` beside it is an
ordinary function, called by its name, and draws an advice saying so.
