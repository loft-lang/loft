# @F50 — Introspection — `loft introspect` (bytecode / native Rust / slot tables)

## What it is

`loft introspect prog.loft` shows you how loft sees your program: the bytecode the interpreter runs, the Rust source the native backend generates, the stack-slot layout, and the resolved types. By default it prints every section; flags like `--show-bytecode`, `--show-rust`, or `--fn <name>` narrow it down.

## How it aids you

It turns "what is the compiler actually doing with my code?" into something you can read. When a program behaves unexpectedly, or you want to understand the cost of a construct, you can look straight at the generated code instead of guessing. `--fn` focuses on a single function so you are not wading through the whole program.

## Example

```
$ loft introspect prog.loft                   # bytecode + generated Rust + slots + types

$ loft introspect --show-bytecode prog.loft   # just the bytecode section
$ loft introspect --show-rust prog.loft       # just the generated Rust
$ loft introspect --fn main prog.loft         # only the function `main`
```
