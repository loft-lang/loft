# @I67 — Opcode implementations

## What it does

Holds the actual behaviour of each bytecode operation — the per-opcode routines the VM dispatches to for arithmetic, comparisons, text and collection operations, and the rest. The file is generated from the `#rust"..."` operator templates in the standard library.
