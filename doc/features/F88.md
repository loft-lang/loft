# @F88 — Stack traces (stack_trace)

## What it is

`stack_trace()` hands a running program its own call stack — a list of frames, outermost call first, each carrying the function name, source location, and the live arguments and variables at that point. It lets code look at how it got to where it is.

## How it aids you

You can print a diagnostic dump, log the path into a failure, or build a custom error report without reaching for a debugger — the same call-stack information a debugger shows, made available to the program itself.

## Example

```loft
fn inner() {
    for frame in stack_trace() {
        println(frame.function);   // outermost first: main, then outer, then inner
    }
}
fn outer() { inner(); }
fn main() { outer(); }
```
