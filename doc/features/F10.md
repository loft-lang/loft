# @F10 — `iterator<T>` values

## What it is

A lazy sequence of values you can loop over one at a time. It produces each value on demand as the loop asks for it, instead of building a whole list up front. The `for` loops you write over ranges and vectors are powered by iterators.

## How it aids you

You can walk through a sequence — a range of numbers, the items of a collection — without ever building or storing the full list, so a loop over a million values costs no extra memory.

## Example

```loft
fn main() {
    total = 0;
    for i in 1..5 {          // steps through 1, 2, 3, 4 one at a time
        total += i;
    }
    println("total={total}");
    // total=10
}
```
