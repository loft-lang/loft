# @F37 — Operator set — arithmetic/comparison/logical/bitwise/unary, `**`

## What it is

The usual operators, all built in: arithmetic (`+ - * / %` and `**` for powers), comparison (`== != < <= > >=`), logic (`and`, `or`, `!`), and bit operations (`| & ^ << >>`).

## How it aids you

Everything you expect for calculating and comparing is there with familiar spelling and sensible precedence, so expressions read the way you would say them aloud — and one line can do real work.

There is one place where it does not, and loft warns about it: a leading `-` is the SIGN of what follows, so it binds tighter than `**`. `-x ** 2` is `(-x) ** 2` — 9 when `x` is 3, where reading it aloud gives -9. The same symbol with a left operand goes the other way (`0 - x ** 2` IS -9), so write `-(x ** 2)` when you mean to negate the power. `warning[unary-minus-binds-tighter]` says so — except when the base is a LITERAL, on the grounds that `-3` reads as one number: `-3 ** 2` is 9 and `-1.5 ** 2.0` is +2.25, both silently.

## Example

```loft
fn main() {
    a: integer = 7;
    b: integer = 2;
    println("{a + b} {a - b} {a * b} {a / b} {a % b} {a ** b}");   // 9 5 14 3 1 49
    println("{a > b} {a == b} {a > 0 and b > 0} {a | b} {a & b}"); // true false true 7 2
}
```
