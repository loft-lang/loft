# @F42 — JSON — json_parse, JsonValue, Type.parse, to_json

## What it is

Turn JSON text into a value with `json_parse(...)`, then read from it: `field(name)` for an object member, `item(index)` for a list entry, and `as_text` / `as_long` / `as_number` / `as_bool` to get a plain value back. `len()` counts a list, and there are matching builders (`json_object`, `json_array`, `json_string`, ...) plus `to_json()` to produce JSON text.

## How it aids you

Work with config files and web responses directly — ask for a field by name or an item by position and get it back in the type you expect — instead of picking the raw text apart yourself.

## Example

```loft
fn main() {
    raw = "{{\"name\": \"loft\", \"version\": 2, \"tags\": [\"fast\", \"typed\"]}}";
    doc = json_parse(raw);
    println("name: {doc.field("name").as_text()}");        // name: loft
    println("version: {doc.field("version").as_long()}");  // version: 2
    println("first tag: {doc.field("tags").item(0).as_text()}");  // first tag: fast
    println("tag count: {doc.field("tags").len()}");       // tag count: 2
}
```
