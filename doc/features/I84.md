# @I84 — Coroutine runtime / yield codec

## What it does

The machinery behind suspendable functions: it lays out a coroutine's saved state and encodes each yielded value so the side that suspends and the side that resumes agree on the exact bytes crossing the yield boundary. Both the interpreter and the native backend share this one layout, so a coroutine behaves identically on either.

`src/coroutine_layout.rs`
