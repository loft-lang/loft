# @F2 — `??` null-coalescing operator (incl. `?? return`)

## What it is

The `??` operator supplies a fallback: `value ?? fallback` gives you `value` when it has one, and `fallback` when `value` is null.

It also fires when a present value does not fit a narrow destination. With `n = 400`, `level: u8 = n ?? 255` stores 255, because 400 does not fit a `u8` (@F4).

Fallbacks chain: `a ?? b ?? c` gives the first of the three that is not null.

The fallback may be `return`, which leaves the function when the value is null: `e = first_even(v) ?? return "none";`. `return` is the only control flow allowed after `??`; `?? continue` and `?? break` do not compile — test the value with an `if` inside the loop instead.

## How it aids you

It turns "this might be missing" into "here is a sensible default" in a single, readable step — no `if`-checks around every optional value. You state the backup once, right where the value is used.

A fallback is a decision, not a repair. `??` fires only on a **null**, so it cannot see a value that is present and wrong — a float divided by zero is an infinity, not a null (@F38), and `x / d ?? 0.0` hands that infinity straight on. Where the failure is not a null, guard the input instead.

## Example

```loft
fn first_even(v: vector<integer>) -> integer? {
    for x in v { if x % 2 == 0 { return x; } }
    null
}
fn describe(v: vector<integer>) -> text {
    e = first_even(v) ?? return "no even number";   // leave the function on null
    "first even is {e}"
}
fn main() {
    missing = null as integer?;
    count = missing ?? 0;       // use 0 when the value is null
    name = "Ada" ?? "unknown";  // keeps the real value when present
    println("{count} {name}");  // 0 Ada
    n = 400;
    level: u8 = n ?? 255;       // 400 does not fit a u8, so the fallback is used
    println("{level}");         // 255
    other = null as integer?;
    println("{missing ?? other ?? 9}");   // chained: the first that is not null, 9
    println(describe([1, 3, 4]));   // first even is 4
    println(describe([1, 3]));      // no even number
}
```
