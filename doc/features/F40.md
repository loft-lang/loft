# @F40 — File & directory I/O (+ durable-store binding)

## What it is

Read and write files on disk. Open a path with `file(...)`, `write(...)` text into it, read it back with `content()`, check whether a path `exists(...)`, and remove it with `delete(...)`. You can also list what is in a folder with `list_dir(...)`.

## How it aids you

Save results and load them back on the next run — settings, saved games, reports — with plain calls that take a path and hand you the contents, so your program remembers things between runs instead of starting from scratch every time.

## Example

```loft
fn main() {
    note = file("greeting.txt");
    note.write("hello from loft");
    reloaded = file("greeting.txt");
    println("read back: {reloaded.content()}");   // read back: hello from loft
    println("exists: {exists("greeting.txt")}");  // exists: true
    delete("greeting.txt");
    println("exists after delete: {exists("greeting.txt")}");  // exists after delete: false
}
```
