# @I57 — Lexer

## What it does

Turns raw loft source text into a stream of tokens — keywords, names, numbers, operators, punctuation — that the parser can consume. It is the first stage of the pipeline and handles character-level details such as comments, string literals, and string interpolation, so later stages never touch raw text.

## Where it lives
