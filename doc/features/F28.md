# @F28 — `for`-in loops — ranges, loop attributes, filtered, `rev()`

## What it is

Repeat a block once for each item in a collection, or for each number in a range.

## How it aids you

Walk a list or count through a range without managing an index by hand — you name the current item and the loop hands you each one in turn.

The forms to know:

- **Ranges:** `1..5` stops before 5; `1..=5` includes it. `rev(1..5)` counts down: 4, 3, 2, 1.
- **A filter:** `for x in v if x > 4 { … }` runs the body only for the elements that pass.
- **Loop attributes** on the loop variable: `x#index` is the element's position, `x#count` is the number of rounds before this one, `x#first` is true on the first round, and `x#remove` removes the current element from the vector safely.
- **Leaving an outer loop:** `a#break` inside a nested loop ends the loop whose variable is `a`.
- **Text** iterates by character: `for c in "héj"` gives `h`, `é`, `j`.

The loop reads its source ONCE, before the first round. Changing the end of a range inside the body does not change the loop; loft warns (`loop-source-written`). Use `while` for a loop whose end moves. Growing the vector you are walking is refused.

A nullable collection is not iterated directly. Write `for x in m ?? [] { … }` or `for x in m? { … }`; an absent collection then gives zero rounds.

## Example

```loft
fn main() {
    total = 0;
    for i in 1..=5 { total = total + i; }
    println("sum 1..=5 = {total}");    // sum 1..=5 = 15

    v = [3, 8, 2, 12, 7];
    for x in v if x > 5 {
        println("{x#index}: {x}");     // 1: 8, then 3: 12, then 4: 7
    }
    for i in rev(1..4) { print("{i} "); }
    println("");                       // 3 2 1
    for c in "héj" { print("[{c}]"); }
    println("");                       // [h][é][j]
}
```
