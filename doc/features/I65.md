# @I65 — Bytecode code generator

## What it does

Emits the individual bytecode instructions during compilation — the routines that decide which opcodes and operands represent each expression and statement. It is the writing end of the bytecode pipeline that the VM later reads.

## Where it lives

`src/state/codegen.rs`
