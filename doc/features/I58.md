# @I58 — Parser (two-pass recursive descent)

## What it does

Reads the lexer's tokens and builds the program's intermediate representation (IR) using a two-pass recursive-descent grammar: a first pass registers every definition (types, functions), so a second pass can resolve references regardless of the order they appear in the source. This is where loft syntax becomes a structured tree.

## Where it lives

`src/parser/` (entry point `src/parser/mod.rs`)
