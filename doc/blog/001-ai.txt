Building a stable language with the use of AI

Loft is not a new language:
- Already 8 years of development prio to AI involvement but not public before it.
- Speed of development is improved by it, but more importantly it got much more complete by it. Constant new features due to comparsion with other languages: julia, ocaml, python

Challenges:
- No memory inside the agents. Everything that needs to be remembered needs to be inside the project. Stale docs, @ tags and tests on almost everything (bugs, features, formal-rules, design-decisions) so things can be found (customer index) and retested. But those things are not unique to AI growing knowledge in a team of people needs the same rigor.
- Bugs are fixed with a narrow scope/vision creating many deviations of routines inside the code without an overall design. The formal rules are a guard against that but they have to be validated constantly to be of use, upside: faster bug fixes due to easier to find logic and less uncertainty about what to implent/fix.
- The many tests that are written given their own problems. Constant worry about efficiency, memory pressure, disk space for running them.

Up-side:
- Working through the night with multiple agents on different aspects of the language.
- Bugs are now found by validation of our rules instead of programmers.
- Quick turn-around, bugs are often fixed within the hour, no something that is easy to match without AI.
- Cost is now 200 euro each month, but that is low relative to taking half a year sabattical before to get the base language in a good shape.
