hex_draw guide

← hex_draw · API reference · source

Draw a small house into the field — floor, walls, a door — and read one wall back as a single flat surface.

hex_draw turns a Plan (a rectangle on the hex lattice: a centre cell, a width and depth in hex steps, one of six rotations and a mirror) into the layers a building is stored as: FLOOR cells, WALL edges, OPENINGS on those edges and a ROOF height field. And it reads a wall back: the edges of one side average to one exact flat surface, which is what a renderer draws and a game collides with.

It is not the storage and not the plan. hex_field holds the cells, edges and heights (HexSet, EdgeSet, Labels, Heights); hex_form owns Plan and the side runs. Reach for hex_draw to draw a building into those, or to recover a wall's surface from them.

use hex_draw::*;
use hex_form::*;
use hex_field::*;
struct House { cells: HexSet, edges: EdgeSet }

A 4 x 2 house on cell (0, 0), floor type 1 and wall material 7.

fn house() -> House {
  h = House { cells: hexset_chunk(-10, -10, 21, 21), edges: edgeset_new(-10, -10, 21, 21) };
  draw_floor(plan(), h.cells, labels_new(-10, -10, 21, 21), 1);
  draw_walls(h.cells, h.edges, 7);
  h
}
fn plan() -> Plan { plan_new(0, 0, 4, 2, 0, false) }
fn main() {
  cells = hexset_chunk(-10, -10, 21, 21);
  types = labels_new(-10, -10, 21, 21);
  edges = edgeset_new(-10, -10, 21, 21);
  floor = draw_floor(plan(), cells, types, 1);
  walls = draw_walls(cells, edges, 7);
  println("floor {floor} cells, walls {walls} edges, floor after walls {hexset_count(cells)}");
  assert(floor == 13 && walls == 26, "5 + 4 + 4 cells; every edge between a floor cell and outside");
  assert(hexset_count(cells) == 13, "a wall is an edge, so it costs no floor");

Four sides

A wall is the boundary of the floor: every edge between a floor cell and a cell outside it. That boundary is closed by construction at any size or rotation. side_edges (from hex_form) sorts those edges onto the plan's four sides — 0 and 2 at the ends of the width, 1 and 3 along it — and gives each one its place t from 0 to 1 along the side.

fn four_sides() {
  h = house();
  counts: vector<integer> = [];
  for s in 0..4 { counts += [side_run_len(side_edges(plan(), h.cells, s))]; }
  assert("{counts}" == "[5,8,5,8]", "the two ends and the two long sides");
  println("sides   : {counts} edges, 26 in all");
}

A door is a material

place_opening puts an opening of nedges edges on a side, centred at t, by writing an opening material onto those wall edges: OPEN_DOOR, OPEN_WINDOW or OPEN_GAP. The wall stays one continuous run, so a renderer can draw a frame there. OPEN_NONE is the value 0, which means NO wall: writing it deletes the edges and splits the wall in two. wall_edge_count counts the edges that still carry a material.

fn a_door_is_a_material() {
  h = house();
  placed = place_opening(plan(), h.cells, h.edges, 1, 0.5, 2, OPEN_DOOR);
  assert(placed == 2 && wall_edge_count(h.cells, h.edges) == 26, "a door: still 26 wall edges");
  g = house();
  place_opening(plan(), g.cells, g.edges, 1, 0.5, 2, OPEN_NONE);
  holes = wall_edge_count(g.cells, g.edges);
  assert(holes == 24, "material 0 removed two edges");
  println("opening : a door keeps 26 wall edges; OPEN_NONE leaves {holes}");
}

A wall reads back as one surface

A wall is stored as a zigzag strip of edges, but it is meant as one flat face. surface_of recovers that face by AVERAGING the side's edges, in exact integers: the summed edge vector is the direction and the mean edge midpoint is the position. Nothing is fitted, so there is no tolerance. surface_is_exact says the direction lies exactly on one of the lattice's twelve headings. Side 1's eight edges have midpoints at y = 2.25, spread evenly either side of x = 0, so that is the surface's mean.

fn a_wall_reads_back_as_one_surface() {
  h = house();
  w = surface_of(plan(), h.cells, 1);
  mx = surface_mean_x(w);
  my = surface_mean_y(w);
  assert(surface_is_exact(w), "the averaged direction is a lattice heading");
  assert(mx == 0.0 && my == 2.25, "the mean of the eight edge midpoints");
  println("surface : side 1 is one flat face through ({mx}, {my})");
}

Draw the straight walls of a structure you know only by its cells, put a door on one, and outline a courtyard.

The first guide draws a house from a Plan: you say where the rectangle is, and the library fills it, walls it and reads each side's surface back. This one starts where that ends. A structure is handed to you as CELLS — an L somebody selected, a house an editor turned by 30 degrees, a road — and nobody says which rectangle it came from, or at what angle. The walls are still there to be read: cells_built reads them off the cells alone.

What comes back is the same WallSurface the first guide met, one per straight wall, so everything that reads a surface (surface_heading, surface_mean_x, surface_meet) reads these too.

use hex_draw::*;
use hex_form::*;
use hex_field::*;

An L as cells: a body 10 hex steps by 6 and a wing 4 by 4 on one end of its far side. Built with two Plans only to have something to draw — from here on nothing remembers them.

fn an_ell() -> HexSet {

What came back

A CellWalls: the cells, their thin walls as an EdgeSet (cw_edges, what draw_walls would have marked), the boundary in walking order with the structure on its left (cw_boundary), the boundary cut into runs — one per straight wall (cw_runs, indices into the boundary) — a surface per run (cw_walls) and the corners (cw_corners: corner i is where wall i meets wall i + 1).

Each wall runs exactly along one of the twelve headings, and each is square to the next: that is a zero dot product in integers, not a float within a tolerance.

fn what_came_back() {
  house = cells_built(an_ell(), 7);
  n = len(house.cw_walls);
  edges = 0;
  for i in 0..n {
    w = house.cw_walls[i]!;
    nx = house.cw_walls[(i + 1) % n ?? 0]!;
    assert(surface_heading(w) >= 0, "wall {i} runs along a heading");
    assert(vec_dot_4(w.ws_dk, w.ws_dm, nx.ws_dk, nx.ws_dm) == 0, "wall {i} is square to the next");
    edges += len(house.cw_runs[i]!);
  }
  assert(edges == len(house.cw_boundary), "every boundary edge is in exactly one wall's run");
  println("headings: {[for w in house.cw_walls { surface_heading(w) }]}");
}

That prints the six headings in order round the L, in twelfths of a turn — 0 is east, 3 north, 6 west, 9 south; the fourth and fifth walls are the notch where the wing ends:

  headings: [0,3,6,3,6,9]

⚠ A wall from cells is not always the line surface_of gives for the same side of a Plan. Along an even heading the two agree exactly. Along an odd heading surface_of averages every edge of the side, the corner's with them, and cells_wall reads the line off the slanted connectors and outvotes the corner's: a few hundredths of a unit apart. Use one or the other for a structure, not both.

⚠ Some cells show no direction. A hex and its six neighbours are the same seven cells at every angle, so cells_axes answers -1 and cells_built falls back on its hint (a heading; 0 when you give none). A structure that small is better kept as an object with a rotation of its own.

A door at a point

On a wall drawn from cells an opening is a KIND, a POINT and a WIDTH. You give the point; cells_place_opening finds the nearest wall, keeps the opening clear of the wall's corners and marks the wall edges under it with the kind (OPEN_DOOR, OPEN_WINDOW) — a material on the edges, never a gap, so the wall stays one wall. cells_openings reads the marks back as centres on the walls' lines and spans of each kind's width.

The walls do not depend on the marks. Build them once and place as many openings as you like on them.

fn a_door_at_a_point() {
  cells = an_ell();
  house = cells_built(cells, 7);
  marks = cells_no_marks(cells);
  sizes = opening_sizes(1.0, 1.0, 0.866);          // a door's width, a window's, the corner clearance

a door in the middle of the first wall, a window a third of the way along the second

  a = house.cw_corners[len(house.cw_corners) - 1] ?? (0.0, 0.0);
  b = house.cw_corners[0] ?? (0.0, 0.0);
  c = house.cw_corners[1] ?? (0.0, 0.0);
  cells_place_opening(house, marks, OPEN_DOOR, (a.0 + b.0) * 0.5, (a.1 + b.1) * 0.5, sizes);
  cells_place_opening(house, marks, OPEN_WINDOW, b.0 + (c.0 - b.0) / 3.0, b.1 + (c.1 - b.1) / 3.0, sizes);
  found = cells_openings(house.cw_boundary, house.cw_runs, house.cw_walls, marks, sizes);
  assert(len(found) == 2, "two openings read back");
  for o in found {
    wide = sqrt((o.op_bx - o.op_ax) * (o.op_bx - o.op_ax) + (o.op_by - o.op_ay) * (o.op_by - o.op_ay)) ?? 0.0;
    println("kind {o.op_kind} on wall {o.op_wall}, over {len(o.op_edges)} edges, {wide:.3} wide");
  }
  assert(found[0]!.op_kind == OPEN_DOOR && found[0]!.op_wall == 0, "the door on wall 0");
  assert(found[1]!.op_kind == OPEN_WINDOW && found[1]!.op_wall == 1, "the window on wall 1");
}

That prints:

  kind 1 on wall 0, over 2 edges, 1.000 wide
  kind 2 on wall 1, over 2 edges, 1.000 wide

The width drawn is the kind's, whatever the wall, and the edges marked are those whose midpoints fall under it: along an even heading they lie 0.87 apart, along an odd one 0.75, so the same door covers different edges on different walls. The span is what to draw; that is what lets one door mesh fit every wall at every angle.

A courtyard

cells_built is for a structure of one piece without a hole. cells_outlines takes anything: it answers one CellOutline per loop of the boundary — the outside of each piece, and one round each hole — every loop walked with its cells on the left, so a courtyard's is walked the other way round.

It is also what draws a road's edge, a stream's bank or a cliff: cells inside and out like any structure, the walls having no height. For those it knows two things a house's outline never needs: where two walls in a row run the same way a short STEP joins them, and a stretch that keeps to a heading off the loop's two axes for six edges or more is a wall of its own, slanted.

fn a_courtyard() {
  cells = hexset_chunk(-24, -24, 49, 49);
  types = labels_new(-24, -24, 49, 49);
  draw_floor(plan_new(0, 0, 12, 10, 0, false), cells, types, 1);
  court = hexset_chunk(-24, -24, 49, 49);
  draw_floor(plan_new(0, 0, 5, 4, 0, false), court, types, 1);
  for r in -24..25 { for q in -24..25 { if hexset_get(court, q, r) { hexset_set(cells, q, r, false); } } }
  loops = cells_outlines(cells, 0);
  println("loops {len(loops)}, walls {len(loops[0]!.co_walls)} and {len(loops[1]!.co_walls)}");
  assert(len(loops) == 2 && len(loops[0]!.co_walls) == 4 && len(loops[1]!.co_walls) == 4, "the hall's outline and the court's");
}

That prints:

  loops 2, walls 4 and 4
